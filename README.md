# 量子技術と電気自動車配送の研究

量子技術の進展が電気自動車配送の運用電力量に与える影響：東京都大田区のラストマイル配送をケースとして

東京都大田区の道路データと配送ベンチマークを用い、経路計算とバッテリー性能の変化が電気自動車による配送の運用電力量に与える影響を研究します。配送需要・時間窓には合成条件を含み、実配送会社の運用再現や地域全体の統計的代表性は主張しません。

## 研究の問い

量子技術の進展は、電気自動車配送の経路計算とバッテリー性能の変化を通じて、ラストマイル配送の運用電力量にどのような影響を与えるか。

## 仮説

同一の充電を考慮した電気自動車配送問題において、古典計算を用いた場合と比較して、量子計算を用いた場合の方が、バッテリー性能の違いによる電気自動車配送の運用電力量の差が大きくなる。

仮説は今後の検証対象であり、確認済みの結果ではありません。

## 計算基盤

道路網・配送条件から、交通経路計算、時間窓付き配送経路問題・電気自動車配送経路問題、制約なし二値二次最適化、全状態ベクトル方式・行列積状態方式シミュレーション、標本抽出、復号・独立物理検証へ接続する基盤です。全状態ベクトル方式と行列積状態方式は、ともに量子回路を古典計算機上でシミュレーションする方式です。

構成図・実道路経路図・時間軸・数値詳細は[計算基盤検証のまとめ](reproducibility/COMPUTATION_PLATFORM_SUMMARY.md)を参照してください。
