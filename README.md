# 量子技術がEV配送の定時配達率と走行時のバッテリー消費電力量に影響を及ぼす仕組みと成立条件

**反証志向型インタビューとRIQによる成立条件の検討**

研究方法の文書版：1.0.1／2026-10-21（Asia/Tokyo）

必要な配送需要を期限内に満たすことと、その配送に伴う走行時のバッテリー消費電力量を抑えることについて、量子技術が従来技術に対してどのように関与し、その関与がどの条件で成立するかを検討する。量子技術の有効性を前提としない。

## 1. 研究目的・研究課題・仮説

### 研究目的

必要な配送需要の充足と、そのサービス提供に伴う運用電力量の低減を両立する観点から、量子技術が電気自動車を用いた配送に影響を及ぼす仕組みと、その効果の成立条件を明らかにする。

量子技術が必ず改善効果をもたらすことを前提とせず、効果が成立しない条件や逆転する条件も対象とする。

### 研究課題

量子技術のうち、どのような技術が、どのような仕組みを通じて、電気自動車を用いた配送の需要充足と運用電力量に影響を及ぼし、その効果はどのような条件で成立するか。

### H1：計算方法の相違による運用電力量への作用

量子計算は、古典計算とは異なる計画取得過程を通じて、配送・充電の運用に作用し、配送需要充足と運用電力量に異なる影響を及ぼし得る。

異なる経路の取得を成立の必須条件とせず、計画取得可否・取得時間等の相違も扱う。

### H2：電池性能の媒介効果

量子化学計算の成果が実用電池性能の改善につながる場合、電池性能の変化は車両・充電条件を通じて、配送需要充足と運用電力量に影響する。

材料計算の成果と、材料・セル・パックを経た実用電池性能の改善を区別する。

### H3：周辺条件による効果の変化

H1およびH2の効果の方向と大きさは、交通状況、運転特性、充電条件等の周辺要因との相互作用によって変化する。

上記の目的・問いはREADMEの採用済み表現、H1〜H3の本文はREADMEに記録された正式凍結版v1.0.1の文言を保持する。正式凍結資料の名称は `RESEARCH_OBJECTIVE_RQ_HYPOTHESES_FREEZE_20261014_v1_0_1.md` であり、公開リポジトリには同梱されていない。仮説の支持・棄却は未判定であり、今回のインタビューを仮説の直接的な因果検証とは位置付けない。

## 2. 3経路と二つの成果

| 経路 | 検討対象 |
|---|---|
| ① | 配送計画 → 計画選択・出発・配達実行 → 定時配達率 |
| ② | 配送計画 → 実際に走った経路・速度・加減速 → 走行時のバッテリー消費電力量 |
| ③ | 材料研究 → 実用化された電池パックの性能 → 走行時の車両質量 → 走行時のバッテリー消費電力量 |

図①-Aは経路①・②の技術比較の前提図、図①-B・図②・図③は3経路の検討図である。図と質問の全文はプロトコルへ集約する。正式仮説に含まれる範囲すべてを面接経路として展開するものではない。電池から定時配達率への直接経路、充電最適化、貨物再割当、車群増強、量子センシング、交通信号制御を新たな主経路にしない。

**定時配達率**は、固定した評価対象の配達のうち、定められた期限までに配達作業を完了した割合である。未配達を分母から除かず、配達先への到着と配達作業の完了、配達の未完了と記録の欠測を区別する。率が同じでも期限内に完了した配達先が同じとは限らないため、各配送先での配達完了状態・完了時刻を保持する。

**走行時のバッテリー消費電力量**は、対象の走行区間で、車両の駆動と車載機器（補機）の消費から、電池に受け入れた回生による回収分（受入回生）を差し引いた正味の電力量である。同一の計量範囲を用い、信号待ち・渋滞などの交通上の一時停止を含め、配達作業の停車・充電・その他の待機を区別する。計算設備・拠点・車外充電損失・製造の電力量は加算せず、端子の正味計測と成分別集計を重複加算しない。未配達による低消費を同じサービスの省電力化としない。

定時配達率は、既存モデルの「期限内需要充足率」に対応する表示名称であり、分母・完了判定・欠測の扱いは変えない。配送計画を取得できた割合とは異なる指標である。正式目的・研究課題・仮説中の「需要充足」「運用電力量」「周辺要因」等は原文を保持し、今回の面接で扱う範囲と区別する。

## 3. 成立条件を検討する面接と分析

配送計画については、一般的な仮説とモデルの前提を先に示し、対象の配送で成立する条件、不成立条件、反例、代替説明を尋ねる。その条件を満たす計画の作成に量子計算が関係する部分、従来計算にも共通する部分、追加的な貢献が未確認の部分を分ける。条件を増やした効果と、同じ条件を量子方式で解く効果を同一視しない。

電池については、容量を一定にして電池パックを軽くする前提を示した後、基礎技術、量子計算の役割と従来との差、性能指標、確認されている数値・比較結果、前提の適否を簡潔に尋ねる。モデルの主な入力は電池パックの重量エネルギー密度（Wh/kg）である。材料の物性・特性、電池セルの性能、電池パックの性能を区別し、数値回答は必須とせず、改善量が不明でも指標と役割を記録する。

補足的に尋ねるのは、時間帯別の交通混雑、信号による停止・再発進、通行規制、迂回路・代替経路の有無などの交通条件である。これらが短時間化と省電力化の両立をどう制約するかを扱う。交通条件の一般的な影響と、従来方式から量子方式へ変更した場合の差が交通条件によってどう変わるかを区別する。交通情報を使った計画変更と交通そのものの制御も区別する。電池性能値の解釈に必要な試験条件は根拠情報として扱う。

中心的方法は、**反証志向型インタビュー**（モデルの成立条件・例外・不一致を引き出す面接）と、**RIQ：Rigorously Interpreted Quotation Analysis**（原発言とモデルの構造を明示的に照合する分析）である。回答票は記録補助である。専門家にパラメータの網羅的抽出やモデル設計を求めず、パラメータは研究者の対応付けに使う。

専門範囲に合わせた図を使い、前提共有 → 対象事例 → 図と中心質問 → 必要な追問 → What-if（仮想条件についての質問） → 記載・根拠確認の順に進める。面接後は、原発言、研究者の解釈、独立資料、仮想的推論を分離して、M0からM1への改訂理由を追跡する。原文との整合と、現実に成立することの証拠は別に判定する。

## 4. 既存定量実験の位置付け

既存実験は、固定顧客集合・単一車両について訪問順を求め、道路旅行時間を評価し、保存した走行軌跡から電力量を別途計算したものである。旅行時間の目的関数へ配達作業時間や待機時間を加えておらず、今回の表示用語変更でも定義を変えない。量子側は3・4顧客の理想状態ベクトルQAOAであり、量子実機や背景交通を含む実運用の効果を実証したものではない。

| 保存結果・条件 | 読み取れる範囲 |
|---|---|
| 3顧客78/78、4顧客64/78の経路取得 | 未取得14件を配送不可能・消費ゼロへ変換しない |
| 共通64条件のうち同一経路59・異経路5 | 削減率の方式差の規模間差はゼロ59・非ゼロ5である。量子優位や定時配達率ではない |
| 電池容量20 kWh、電池パックの重量エネルギー密度180・220・250 Wh/kg | 固定軌跡の質量感度分析であり、量子由来の性能改善値ではない |
| 平坦路、回生なし、補機除外、積載質量0 kg | 限定的な駆動電力量モデルであり、最終成果指標全体や実配送の積載を再現しない |

数値・実行状態の正本は[最終定量報告](01_research_design/scenario_evaluation/final_quantitative_study_20261008/FINAL_QUANTITATIVE_STUDY_REPORT.md)、条件は[Controlled-DC凍結仕様](01_research_design/methodology/CONTROLLED_MASS_TO_DC_MODEL_FREEZE.json)、工程・限界は[定量研究ガイド](docs/QUANTITATIVE_GUIDE.md)を参照する。今回、科学計算・再集計・凍結結果の改訂は行っていない。
