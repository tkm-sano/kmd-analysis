# Presentation Asset Map Guide

The canonical presentation contains 22 slides and 110 embedded media items. Slide-level text, media hashes, notes, links, candidate sources, and reproduction status are recorded in `008_20260712_presentation_asset_map.csv` and summarized in `009_20260712_presentation_asset_map.md`.

The asset map distinguishes embedded presentation media from source figures and data. No exact byte-for-byte media match was found in the pre-cleanup repository because PowerPoint may transform or re-encode inserted assets; candidate generators are therefore assigned through filenames, slide content, and static code/data dependencies.
