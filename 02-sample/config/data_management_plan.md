# データ管理方針

本環境は、公開統計と公開文献を中心に用いる静学的反実仮想比較を前提とする。したがって、標準運用では個人データを直接扱わない。

## 1. データ区分
- 公開統計原ファイル
- 文献本文・抽出メモ
- 加工済み分析入力
- 推定結果
- 図表・説明資料

## 2. 保存原則
- 原ファイルは `data/raw/` に保存する。
- 実行入力は `data/actual_input/` に保存する。
- 出力は `data/output/` に保存する。
- 取得日、出典、加工の有無を記録する。

## 3. 公開原則
- 可能な範囲ではコード、テンプレート、抽出規則、設定ファイルを公開する。
- 利用規約や著作権により再配布できない原資料はURL参照にとどめる。
- 公開できない場合は理由を記録する。

## 4. 倫理
- 個票や匿名データを後日用いる場合には、目的限定、最小化、アクセス制御、保存期間明示、必要な審査手続を別途行う。
