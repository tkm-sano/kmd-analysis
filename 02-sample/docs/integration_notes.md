# 文献抽出表と実行入力の関係

本環境では、研究計画書の設計と実行スクリプトの要件を両立させるために、文献関連の入力を二段階で扱う。

## 1. 抽出段階
`benchmark_evidence_extraction_template.csv` を用いる。ここでは文献に書かれた元の値を、可能な限りそのまま記録する。`budget_raw` と `budget_unit` はこの段階で保持する。

## 2. 実行段階
`benchmark_evidence_model_input_template.csv` を用いる。ここでは比較可能性のために正規化した `cost_index` を記録する。実行スクリプトはこの表を直接読む。

## 3. 比較統合段階
`benchmark_computer_template.csv` は、同一の産業群・問題類型の内部で古典条件と量子条件を対応づけた後の表である。これは中間生成物であり、通常はスクリプトが生成する。

## 4. 実務上の推奨
- 文献本文から直に実行入力を作らず、必ず抽出段階を経由する。
- 一次文献、レビュー、専門家判断を区別する。
- 正規化規則は別紙または note に残す。
