# 環境統合メモ

本環境は、研究計画で想定されている三層の作業を接続するために構成した。

第一に、`sources/` と `config/` は、文献レビューおよび公式統計取得の起点である。ここには、どのデータ源・文献をどの目的で用いるかを一覧化したファイル、ならびにレビュー手順とデータ管理方針を置いてある。

第二に、`data/templates/` は、実証分析に先立って整備すべき中間入力の雛形である。とくに上流については、研究計画書の記述どおり、文献抽出段階とモデル投入段階を分ける必要がある。そのため、`benchmark_evidence_extraction_template.csv` と `benchmark_evidence_model_input_template.csv` を分けて置いてある。

第三に、`src/` と `data/output/` は、実行と再現の層である。`run_quantum_commuting_model.py` は既存の実装本体であり、`run_analysis_environment.py` はそれを統合環境の標準ファイル名で呼び出すラッパーである。`validate_inputs.py` は、列不足や基本的な欠損を事前に検出するための補助スクリプトである。

この構成により、研究計画書で求められていた「文献レビューの検索式・採否基準・抽出表・前処理コード・推定コード・図表作成コードを一体の再現パッケージとして管理する」という要件に沿う作業環境となる。
