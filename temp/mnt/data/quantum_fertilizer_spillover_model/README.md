# 量子技術の窒素固定実装による食料・健康・社会保険波及効果モデル

本プロジェクトは，以下の仮説連鎖を，実行可能なサンプル分析として Python で再現するための最小構成である。

1. 量子コンピュータの実装により，窒素固定のエネルギー効率が改善する。
2. それにより，肥料生産に必要なエネルギー量が下がる。
3. 肥料費の低下が野菜価格の低下につながる。
4. 野菜価格の低下によって，需要供給関係のもとで供給量および摂取量が増える。
5. 野菜摂取の改善により，食生活由来の生活習慣病負担が軽減し，社会保険料負担相当額が下がる。

## 注意

このプロジェクトは**仮説検証用のサンプル実装**である。入力データにはサンプル値を含み，疫学係数や費用連関も簡略化している。そのため，出力結果は政策的事実ではなく，研究設計と分析パイプラインの雛形として解釈する必要がある。

## フォルダ構成

- `main.py` : 全体実行ファイル
- `config/sample_params.yaml` : モデル仮定
- `data/population_groups.csv` : 所得群別の人口・野菜摂取サンプル
- `data/disease_burden.csv` : 疾患別負担サンプル
- `src/model.py` : 因果連鎖モデル本体
- `src/analysis.py` : データ読込・分析・図表出力
- `src/report.py` : レポート生成
- `outputs/` : 実行後に結果と図表を保存

## 実行方法

VSCode でこのフォルダを開き，必要なライブラリをインストールしたうえで，`main.py` を実行する。実行後，`outputs/sample_report.md` にレポートが生成される。

## 主な出力

- `outputs/summary_metrics.csv`
- `outputs/group_results.csv`
- `outputs/disease_results.csv`
- `outputs/sample_report.md`
- `outputs/figures/*.png`

## モデルの考え方

本モデルは，窒素固定効率の改善が肥料コストを通じて野菜価格へ波及し，さらに価格変化が摂取行動と疾病負担へ連鎖するという縮約モデルである。価格・数量の変化は，需要弾力性と供給弾力性を用いて均衡変化として近似する。推奨摂取量達成人口比は，所得群ごとの摂取分布を正規分布で近似して算出する。健康寿命については，疾患別 DALYs の減少量を人口で割った近似指標を用いる。

## 変更しやすい箇所

- 仮定値を変える場合は `config/sample_params.yaml` を編集する。
- サンプル人口構成や摂取分布を変える場合は `data/population_groups.csv` を編集する。
- 疾患別の負担や医療費を変える場合は `data/disease_burden.csv` を編集する。
