# mnt Folder Analysis Report

## 対象
本レポートは、リポジトリ内で確認できた `mnt` ディレクトリである `temp/mnt` を対象に作成した。

## 結論
`temp/mnt` の中身は、一般的な「生データ置き場」ではなく、`quantum_fertilizer_spillover_model` というサンプル分析プロジェクト一式である。

このプロジェクトは、README に明記されている通り「仮説検証用のサンプル実装」であり、量子コンピュータの実装で窒素固定の効率が改善した場合に、

- 肥料生産エネルギー
- 肥料価格
- 野菜価格
- 野菜摂取量
- 疾病負担
- 社会保険料負担相当額

へどのような波及が起こるかを、簡略モデルで試算するためのデータとコードをまとめたものになっている。

つまり、ここにあるのは主に以下の3種類である。

1. 分析条件を与えるサンプル入力データ
2. その入力を処理する Python コード
3. 実行済みのサンプル出力データと図表

## これはどんなデータか
このデータは、実測の統計原票や外部公開データセットそのものではない。内容から判断すると、以下の性質を持つ。

- 仮説駆動のシナリオ分析データ
- 説明用・試作用のサンプル値
- 再現可能な分析パイプライン一式

README には「入力データにはサンプル値を含み、疫学係数や費用連関も簡略化している」とあるため、政策判断や現実の推計値としてそのまま使うデータではない。むしろ、

- どんな変数が必要か

を示す雛形データと見るのが適切である。

## コードから見たデータの流れ
`src/analysis.py` と `src/model.py` を確認すると、流れは次の通り。

1. YAML と 2 つの CSV を読み込む

## 使用モデル
使用されている中心モデルは `src/model.py` に実装された `QuantumFoodHealthModel` である。性質としては、統計的推定モデルや機械学習モデルではなく、仮定値に基づく縮約型の決定論的シナリオモデルである。

主なモデル構造は以下の通り。

### 1. 価格波及モデル
量子技術による窒素固定効率の改善率を起点に、

- 窒素固定効率改善
- 肥料生産エネルギー削減
- 肥料価格低下
- 野菜生産コスト低下
- 野菜価格変化

へ順に伝播させる。ここでは pass-through 率やコスト比率を掛け合わせる形で計算している。

### 2. 需要供給の縮約均衡モデル
野菜価格の変化から数量変化を求める部分では、需要弾力性と供給弾力性を使った簡略均衡モデルを使っている。これは市場全体の反応を近似するもので、実データから回帰推定したものではない。

### 3. 所得群別摂取量モデル
人口を所得5群に分け、各群の

- 基準摂取量
- 摂取量の標準偏差
- 価格感応度

を使って、価格低下時の摂取量増加を計算している。群別の増加幅は `price_sensitivity_multiplier` によって差が付く。

### 4. 推奨摂取量達成率の正規分布近似
各群で推奨摂取量 350g/日を超える人の比率は、平均と標準偏差から正規分布の累積分布関数を使って近似している。これは分布仮定による割合計算であり、統計検定ではない。

### 5. 健康影響モデル
平均野菜摂取量の増分に応じて、疾患ごとのリスクが比例的に低下すると仮定している。各疾患について、

- 基準発症率
- DALYs
- 年間医療費
- 10g 当たりのリスク低下率
- 最大リスク低下率

を使って、症例減少数、DALY 減少、医療費減少を計算している。

### 6. 社会保険料負担への連結モデル
医療費減少額に `medical_cost_to_premium_linkage` を掛けて、社会保険料負担相当額の減少へ変換している。これも制度財政の厳密推計ではなく、連関を簡略化したリンクモデルである。

### 7. 統計検定モデル
統計検定としては、個票データが存在しないため、群別・疾患別の集計差分に対して exact sign test を使っている。これは差分の大きさではなく、差分の符号が仮説方向にどれだけ一貫しているかを評価する厳密二項検定ベースの方法である。

このため、ここでの検定は「母集団平均の差を推定する検定」ではなく、「シミュレーション結果が全群・全疾患で同じ方向に動いているかの確認」に近い。

## モデル解釈上の補足
このモデルは、以下の特徴を持つ。

- 決定論的であり、乱数シミュレーションは行っていない
- 推定ではなく、設定値に基づいて結果が一意に決まる
- 統計検定、p 値、信頼区間、回帰係数推定は含まれていない
- 実証分析というより、因果連鎖を見通すための試算モデルである

## 分析上の注意点
このフォルダのデータを扱う際は、以下に注意したい。

- サンプル値が含まれており、実測値とは限らない
- 疫学的な関係や価格転嫁は単純化されている
- 結果は現実の予測値ではなく、因果連鎖の例示に近い
- 実務利用には、肥料市場、野菜価格、摂取実態、疾病負担、社会保険財政の実データ差し替えが必要

- 実測の単一データセットではない

## 社会的インパクトの示唆
このサンプル結果からは、基礎技術の改善が単なる生産効率向上にとどまらず、食料アクセス、公衆衛生、社会保険負担まで含む横断的な社会的インパクトを持ちうることが示唆される。定量的には、野菜平均価格は 420.0 円/kg から 412.9 円/kg へ約 1.7% 低下し、平均野菜摂取量は 283.00 g/日から 286.37 g/日へ 3.37 g/日増加する。推奨摂取量達成人口比は 19.06% から 20.32% へ 1.263 パーセントポイント改善しており、総人口 1.25 億人前提では、推奨水準に達する人が概算で約 158 万人増える規模感になる。

健康・財政面では、DALYs 総減少量が 14,158.10、社会保険料負担相当額の減少が年約 48.6 億円と試算されている。これは 1 人あたりでは小幅でも、人口全体に広げると無視できない改善規模になりうることを示している。

ただし、これは実測データから因果効果を推定した結論ではなく、サンプル前提値に基づくシナリオ分析から得られる示唆である。したがって、実際の政策的含意を論じるには、実データを用いた再推計と感度分析が必要である。
