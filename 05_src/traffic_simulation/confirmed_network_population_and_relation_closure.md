## 1. この文書の目的

この文書は、大田区道路網について確定・受理した道路母集団と関係データ参照補完を
まとめる。未解決事項を追跡する文書ではない。機械可読な正本は
`reproducibility/config/traffic_simulation/relation_closure_v16.yml`、入力、出力、
SHA-256、実行コマンドを含む監査記録は
`03_data/metadata/acquisition/20260730_ota_ward_relation_closure_v16.md`である。

## 2. 確定した設定

| 項目 | 確定内容 |
|---|---|
| 設定識別子 | `ota_ward_relation_closure_v16` |
| 設定版 | 16 |
| 実行識別子 | `ota-ward-relation-closure-v16-20260730-01` |
| 地域原本 | Geofabrik関東2026-07-16 |
| 分類前入力 | 大田区取得範囲の地図データと、地域原本から再帰補完した参照要素 |
| 通常規制 | `type=restriction`を保持 |
| バス向け規制 | `type=restriction:bus`を通常規制と分けて保持 |
| 未登録規制 | 未登録の`restriction:*`は破棄せず停止 |

v15では`type=restriction:bus`が3件除外されていた。v16では、通常の右左折規制と
バス向け規制を別カテゴリとして保持し、参照構成点、道路、入れ子の関係データを
地域原本から再帰的に補完する。

## 3. 保持したバス向け規制

| 関係データ識別子 | 地図上の規制表現 |
|---|---|
| `16016504` | バスは直進のみ許可 |
| `16016506` | バスの直進を禁止 |
| `16026064` | バスは直進のみ許可 |

これら3件を保持したことは、元の地図表現を分類前入力へ残したことを意味する。
SUMOの車線間接続へ規制を反映し終えたことは意味しない。

識別子の重複は、構成点、道路、関係データの名前空間ごとに検査する。例えば、
`node/1`と`way/1`は異なる要素であり、重複とは扱わない。

## 5. 道路の役割と母集団

| 役割 | 定義 | 道路数 |
|---|---|---:|
| 属性解決候補 | 自動車系道路ホワイトリストへ一致 | 26,220本 |
| 最終分析対象 | N03大田区境界と道路形状が交差 | 13,494本 |
| 道路構造維持用 | 保持した関係データの構造維持に必要だが最終分析対象外 | 555本 |
| 除外する原本文脈 | 上記のいずれにも該当しない閉包内道路 | 309,360本 |

役割は閉包内の全323,409道路について排他的である。道路構造維持用であることは、
その道路を配送分析対象へ採用することを意味しない。

v15との比較では、属性解決候補道路の追加は0本、削除は0本、不変は26,220本である。
バス向け規制3件は新しい規制意味を追加したが、その構成道路は既に入力に存在したため、
属性解決候補道路数は変わらない。

## 7. この確定が意味しないこと

次の事項は、この文書で確定した範囲に含まれない。

- 道路属性の重要度分類と採用値は確定していない。
- v15の全件分類結果をv16の正式結果として再利用できない。
- バス向け規制はSUMOの車線間接続へまだ反映していない。
- 通行可能車種、交差点、信号、最終道路網は未承認である。
- 正式道路網、交通モデル較正、配送比較へ進める状態ではない。

後続作業の未解決事項は`current_issues_and_blockers.md`で管理する。
