## 1. この文書の目的

この文書は、実装済み、実行済み、または受理済みであることを証拠によって確認した
事項だけを記録する。未実装、未実行、未承認の事項は
[`current_issues_and_blockers.md`](current_issues_and_blockers.md)で管理する。

機械可読な現在地の正本は
`reproducibility/config/traffic_simulation/research_stage.yml`、要件実装状態の正本は
`reproducibility/config/traffic_simulation/requirements_traceability.yml`である。
本書はそれらを置き換えず、確定事項を人間が確認できる形で説明する。

## 2. 道路母集団と関係データ参照補完

バス向け規制3件を含む`ota_ward_relation_closure_v16`の入力、参照完全性、母集団、
出力SHA-256および再実行一致は受理済みである。件数、識別子、ハッシュおよび
受理範囲は
[`confirmed_network_population_and_relation_closure.md`](confirmed_network_population_and_relation_closure.md)
に分離して記録している。

この受理は道路属性の値、SUMO車線間接続、信号または正式道路網の承認を意味しない。

## 3. 道路属性停止時の安全条件

道路属性解決処理には、次の安全条件を実装済みである。

- 停止行を、通常規則、構造確認用規則、例外規則、追加証拠要求のいずれか一つへ
  排他的に分類する。
- 停止でない行に停止区分が付いた場合はエラーとする。
- 各保持道路について、一方通行、車線数、最高速度の監査行を正確に一件ずつ残す。
- 通行権限について、停止、前提属性による未実行、方向・車線別採用のいずれかを
  必ず記録する。
- 前提属性による未実行を独立阻害として重複計上しない。
- 停止中は正規化XMLを公開せず、通行権限期待値を`complete=false`とする。

固定試験では、正式用の欠損が追加証拠要求、構造確認用の欠損が構造確認用規則へ
分類されることを確認済みである。

## 4. 属性別重要度分類

次の実装と契約を確認済みである。

- 述語、分類専用、分類・解決統合など5種類のJSON Schema
- 判定事実生成処理
- 車線数を`L0`から`L3`、最高速度を`S0`から`S3`へ分類する処理
- 重要度、選択規則識別子、一致規則識別子だけを出力する分類専用成果物
- 分類処理が属性値または解決操作を出力しないこと
- 道路属性解決処理の読取境界が分類オブジェクトを上書きしないこと
- RFC 8785によるレコード正規化ハッシュ
- 正常、異常、境界、再実行、規則改訂、分類非上書きの試験

独立oracleはproduction classifierより前に作成され、実装出力に合わせて変更して
いない。固定SHA-256は次のとおりである。

```text
98b6a007e4828e42570a17d9255bdd029295afddf6307d1a6f3f63f8bc96664a
```

独立した人間によるfixture reviewは研究責任者判断で省略した。この判断は
`review.json`へ記録済みであり、独立受理済みとは扱わない。

## 5. 307件の規則・データ例外の排他的分類

v15の停止記録に含まれる307件について、日本・東京の法制度とOSM表現に対応する
20規則を実装し、全行を排他的に分類した。

| 検証項目 | 確定結果 |
|---|---:|
| 対象行 | 307 |
| ちょうど一つの規則へ一致 | 307 |
| 一致なし | 0 |
| 複数一致 | 0 |
| 実装済み分類規則 | 20 |

通常例、異常例、境界例と、実装から生成していない独立正解を固定した。未知規則は
0一致、重複規則は2一致として停止する。規則、固定データ、実行記録は次にある。

- `specifications/japan_tokyo_osm_exception_classification_rules.md`
- `validation/fixtures/resolver_exception_rules/`
- `03_data/metadata/acquisition/20260730_ota_ward_v15_exception_rule_validation.md`

この結果は例外種別の分類完了を意味し、属性値の解決完了を意味しない。

## 7. 検証結果

固定`analysis`コンテナによる交通シミュレーション検証一式は、版16属性値解決実装後の
直近実行で`355 passed`である。固定試験用データの独立正解結果は変更されておらず、
版16全件成果物はスキーマ検査と意味整合検査に合格した。

検証合格は、試験対象となった実装契約について既知の不合格がないことを意味する。
実データの正式道路網が完成したことや、未実装工程の正しさを意味しない。

## 8. 確定範囲の限界

本書の確定事項には、次を含まない。

- 明示値、外部証拠、モデル値または代替値を採用する属性値解決
- v16母集団に対する全道路・全属性・両profileの分類・解決
- 通行権限のSUMO車線・車線間接続への反映
- 仮道路構造、交差点、信号および最終`net.xml`の正式生成
- 交通モデルの較正と独立検証
- 正式コスト行列、配送比較およびQAOA評価

これらは未解決事項文書に残し、合格証拠が固定された時点で本書へ移す。
