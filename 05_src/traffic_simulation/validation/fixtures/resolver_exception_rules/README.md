# 道路属性例外分類の試験用固定データ

`cases.json`は通常例、異常例、境界例を固定した入力である。20個の通常例は決定表の
各規則を一度ずつ通り、境界例は日本の速度種別、勧告速度と法定最高速度の併記、
対象外車種キーの境界を確認する。異常例は壊れたJSONと未知の導出方法が暗黙に
通過しないことを確認する。

`oracle.json`は実装出力から生成せず、規則の意味から手作業で作成した正解結果である。
本番コードに合わせて正解を変更してはならない。規則変更時は、変更理由、根拠、
適用日を決定表と規則文書へ先に記録し、その後に正解結果を独立に再検討する。

このfixtureが検証するのは「どの例外規則へ分類するか」である。速度値、車線数、
通行可能車種を採用できることは示さず、各規則の解決条件が未完了なら停止を維持する。
