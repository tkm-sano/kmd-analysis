# Simulation Report

## このダミーデータとは何か

この report で使っているデータは、実測の確定版ではなく、パイプラインの挙動確認のために作成したテンプレートとダミー値である。都市、産業群、計算条件、エネルギー価格、基準流入、都市条件指数は、分析フローが最後まで動き、変数間のつながりを確認できるように整えた最小実行用のサンプル入力である。

そのため、この report の数値は現実世界を直接推定した結果ではない。ここでの主な目的は、「どの入力がどの指標に効くか」「符号や差分の向きが意図通りか」「不確実性を入れるとどのくらい幅が出るか」を確認することであり、政策判断や実務予測にそのまま使う前には実データへの置き換えが必要である。

実行日: 2026-04-11

実行コマンド:

```bash
MPLCONFIGDIR=/tmp/mplconfig python -m src.run_pipeline
```

本 report は、`2025` のみを対象とする現在の設定で、感度分析とモンテカルロを含めて再生成した。

## 何を改善したか

今回の更新では、従来の決定論的な比較を次のように組み替えた。

1. 探索性能、採用率、コスト弾力性を独立したレバーとして感度分析できるようにした。
2. `n_replicates` を使い、3 レバーに分布を与えたモンテカルロを追加した。
3. 流入式を見直し、自動車流動だけでなく非自動車流動も部分的にコスト変化へ反応するようにした。
4. 都市ごとの賃金指数と集積指数を入れ、都市別の魅力度と弾力性を分けて扱うようにした。
5. ANOVA は補助指標として残しつつ、分析の中心を感度分析と不確実性評価へ移した。

## ベース結果

量子条件 `quantum_enabled` は、全産業で探索性能指数を押し上げた。`classical_only` 比での上昇率は `+9.65%` から `+12.52%` だった。

この改善は工学変換後の燃費改善率にも反映され、単位コストは全産業で低下した。その結果、流入シミュレーション総量は `classical_only = 41425.15`、`quantum_enabled = 41455.21` で、差は `+30.06`、割合差は `+0.073%` だった。

都市別差分では `tokyo +9.96`、`osaka +6.15`、`nagoya +5.07` の順で大きく、産業別差分では `metal +15.31 (+0.098%)`、`chem_polymer +9.64 (+0.067%)`、`inorganic +5.10 (+0.045%)` の順だった。

## 感度分析

今回の中心分析は、`search_multiplier`、`adoption_multiplier`、`elasticity_multiplier` を独立に振った感度分析である。

総流入差 `quantum - classical` の変化は次の通りだった。

- 探索性能倍率 `0.85 → 1.15`: `+25.46 → +34.70`
- 採用率倍率 `0.85 → 1.15`: `+27.66 → +32.30`
- 弾力性倍率 `0.85 → 1.15`: `+25.55 → +34.57`

この結果から、現在の設定では `search_multiplier` と `elasticity_multiplier` の効きが比較的大きく、`adoption_multiplier` は効くが変動幅はやや小さいと読める。つまり、量子条件の差を押し広げる主要チャネルは「探索性能の改善そのもの」と「コスト変化に対する流入の反応強度」であり、採用率はその次のレバーである。

重要なのは、3 レバーを独立に振っても差分の符号は一貫して正だったことだ。したがって、今回のモデルでは「量子条件が効くかどうか」よりも、「どのレバーを強めると差が広がるか」を見る方が有益である。

## モンテカルロ

`n_replicates = 50` を使い、3 レバーに正規分布ベースのゆらぎを与えたモンテカルロを実行した。

- `delta_abs` の平均: `23.37`
- `delta_abs` の標準偏差: `2.46`
- `delta_abs` の 5-95 パーセンタイル: `19.54 - 26.78`
- `delta_pct` の平均: `0.056%`
- `delta_pct` の 5-95 パーセンタイル: `0.047% - 0.065%`

これにより、今回の仮定の範囲では、量子条件による流入差は正方向を保ちながらも、その大きさはかなり小さい帯域に収まると読める。確率性を入れても「大きな変化」にはならず、「小さいが一貫して正方向の差」という性格が強い。

## ANOVA はどう読むか

ANOVA は補助指標として残している。見るのは次の 3 つである。

- `C(destination_city_id)` の主効果: 都市ごとの基準流入差
- `C(compute_condition)` の主効果: 量子条件の全体差
- `C(destination_city_id):C(compute_condition)` の交互作用: 都市ごとの効き方の違い

結果は、`C(destination_city_id)` の主効果は全産業で有意かつ大きく、`partial_eta2` はおおむね `0.47 - 0.52` だった。一方で、`C(compute_condition)` と交互作用は非常に小さく、今回の単年・ダミーデータでは都市差が支配的であることを再確認する結果になった。

したがって、今回の分析で優先して読むべき順序は `都市差 > 感度レバー差 > 計算条件主効果 > 交互作用` である。

## 解釈

今回の改善後の分析は、「量子条件を入れると流入が増えるか」を単に見るのではなく、「どの仮定がその差を作っているか」と「その差が不確実性込みでどの程度か」を見るものになった。

その読み方に立つと、結論は次のようになる。

1. 量子条件の差は正方向だが、絶対量としては小さい。
2. 差を押し広げる主要因は、探索性能の改善幅とコスト弾力性である。
3. 採用率も効くが、現在の設定では上の 2 要因より感度はやや小さい。
4. 都市差は依然として強く、都市ごとの基準流入規模が結果を大きく支配する。
5. モンテカルロを入れても、差は正方向だが狭いレンジに収まる。

したがって、この出力は「量子条件の大きな実証効果」を示すものではなく、「現行の仮定表と改良後の流入式のもとで、差分を作る主要レバーが何かを切り分けたシナリオ分析結果」と位置づけるのが適切である。

## 考察

今回の結果からみると、量子条件の効果は「あるかないか」よりも、「どの経路を通じて小さく効いているか」を見る方が重要である。とくに探索性能とコスト弾力性の感度が比較的大きいことは、材料探索段階の性能改善だけでは十分でなく、その改善が実際のコスト低下として意思決定に効く強さまで含めて設計しないと、都市流動には大きく波及しにくいことを示している。

また、都市差が依然として支配的であることは、計算資源条件の改善だけで都市間競争力が大きく入れ替わるわけではないことを示唆する。今回のモデルでは、量子条件は既存の都市優位を上書きするというより、もともと流入規模の大きい都市に小さな上乗せを与える性格が強い。これは、技術条件の改善を地域政策へ接続するには、賃金、集積、人材、交通などの都市側要因と一体で考える必要があることを意味する。

さらに、モンテカルロを入れても差分のレンジが比較的狭かったことは、現在の仮定範囲では結論の符号が安定している一方、効果量は限定的であることを示している。逆にいえば、今後この分析を実務に近づけるには、単に反復回数を増やすより、どの入力分布を置くか、どの都市属性を追加するか、そして量子条件が探索性能以外の経路にも効くのかを見直すことの方が重要である。

## 解釈上の注意

今回の流入式は、従来の `base_car` のみ反応する形から改め、非自動車流動も部分反応させ、さらに都市の賃金指数と集積指数を魅力度と弾力性の両方に入れている。それでもなお差分が小さいため、現行ダミーデータの範囲では、量子条件の影響は「存在するが限定的」という読みが自然である。

実データに置き換える際は、特に次の 3 点が結果を大きく動かす可能性が高い。

- `compute_resource_conditions.csv` の探索性能差
- `industry_group_master.csv` のコスト弾力性
- `city_master.csv` と `city_condition_index.csv` に置く都市魅力度の尺度
