# Research repository inventory v17

Inventory is generated by extension and path role; generated outputs are evidence, never authority. The machine-readable [Markdown inventory](markdown_inventory_v17.yml) is regenerated by `validate_current_markdown_index.py --write-inventory` and is intentionally separate from normative documents.

Lifecycle taxonomy: `CURRENT`, `SUPERSEDED`, `HISTORICAL`, `DRAFT`, `GENERATED`, `DEPRECATED`, `UNKNOWN`.

Role taxonomy: `DECISION`, `NORMATIVE_SPECIFICATION`, `RESEARCH_NOTE`, `CONFIGURATION`, `REGISTRY`, `SCHEMA`, `MANIFEST`, `BASELINE`, `ACCEPTANCE`, `VALIDATION_REPORT`, `DIAGNOSTIC`, `PORTAL_HANDOFF`, `REPOSITORY_INDEX`, `PIPELINE_SPECIFICATION`, `CURRENT_STATE_POINTER`.

For each discovered Markdown/YAML/JSON file the inventory records path, inferred title/ID, role, lifecycle, authority flag, generated flag, hash-bound/reference status, Portal/validator dependencies, move safety, and recommended destination. Ambiguous files are `UNKNOWN` and are not moved automatically.

Canonical current authority and logical map are defined in `research_repository_index_v17.yml` and `20260903_20260903_research_repository_map_v17.md`.
