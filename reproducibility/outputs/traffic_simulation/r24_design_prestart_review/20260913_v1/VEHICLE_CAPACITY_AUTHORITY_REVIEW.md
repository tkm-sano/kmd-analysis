# Vehicle capacity authority review

Status: `DERIVED_CAPACITY_AVAILABLE`, but `STOP_CAPACITY_AUTHORITY_INSUFFICIENT` remains for production R24.

The repository contains official payload evidence, including 350 kg for several F1 vans, about 950–1,050 kg for F4, and 2,000 kg for F5. The vehicle-population document says these are evidence envelopes and that the active managed profile is not a frozen experimental scalar capacity. The registry also states formal vehicle count and capacity remain unfixed.

A parcel-equivalent demand unit cannot be paired directly with kg. R24 must either obtain a parcel-level mass authority or define an approved normalized load unit and a capacity in that same unit. A defensible first protocol is a normalized experimental capacity record, with payload source retained as contextual evidence, and an explicit statement that it is not a kg claim. No absolute `Q` is selected by this review.
