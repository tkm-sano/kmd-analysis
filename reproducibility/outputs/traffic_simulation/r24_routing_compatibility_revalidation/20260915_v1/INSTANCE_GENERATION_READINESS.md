## Readiness verdict

`INSTANCE_GENERATION_INPUT_READY = YES_WITH_LIMITATIONS`

The final eligible frame, stable IDs, methodological demand, current edge-offset proxies, network hash, vehicle class and population-level reachability are now materialized.

Potential suites can consume the same filtered manifest:

- Repeated Random: `SRSWOR(C_eligible,n)` is technically possible.
- Controlled Structural: clustered/dispersed/mixed construction is technically possible from coordinates/network, but its metrics, thresholds, nesting and tie rules must be frozen first.

Instance generation does not begin in this stage. The policy is not yet sufficiently frozen to jump directly to a benchmark manifest: values of `n`, repetitions/seeds, suite allocation, structural definitions, anchor IDs, duplicate handling and failure/no-redraw policy still need one authoritative specification.

Every generated instance must subsequently compute all ordered-pair run_3 OD values, validate connection transitions, record zero arcs and apply the already frozen capacity contract. Population SCC is not an OD cost matrix.
