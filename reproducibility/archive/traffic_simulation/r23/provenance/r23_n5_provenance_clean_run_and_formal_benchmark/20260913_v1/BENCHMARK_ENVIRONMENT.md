# Benchmark environment

All repetitions ran in `/home/takuma/.conda/envs/evrp-quantum-temp` on the same host process environment. Python 3.11.16, Qiskit 2.5.2, Aer 0.17.2, Algorithms 0.4.0, Optimization 0.7.0, NumPy 2.4.6 and SciPy 1.17.1 were used. The benchmark source commit was `1fcd08e7df887053a40d88d15efbc1e517ab84ed`. Thread and affinity controls were not fully captured in this small runner, so claims remain limited.
