# 修論用記述案

本研究は、大田区の単一拠点を想定し、配送先の車両割当てと訪問順序を対象とする。京浜トラックターミナル内の丸運営業所では関係会社を含む16台、国内類似拠点の松戸事例では31台が確認できたが、同時計画の対象車両数と出発前の計画時間は確認できなかった。したがって5台500配送先・10台1,000配送先を研究上の主条件、20台2,000配送先を拡張条件とし、30台3,000配送先は実運用再現規模として保留し、合成負荷による上限試験に限定する。60・300・900秒は実運用の締切ではなく感度分析とする。全体古典VRPとの比較と、共通初期解の同一部分問題を古典または量子候補で改善する比較を分離する。

今回の予備計測ではPyVRP 0.12.0による合成3,000先の実行可能解を検証した。大田区の全道路ODによる同規模の検証と、量子候補を含む複数台比較は未実行である。既存の単一車入力460件（最大125先）と今回の合成予備計測を、実営業所で実証された配送規模とは扱わない。

出典：[丸運「詳細」](https://www.maruwn.co.jp/corporate/network/keihin-terminal/)、[ヤマト資料PDF4頁上段／スライド6](https://www.cao.go.jp/consumer/iinkaikouhyou/2021/doc/202108_winwin_jirei_3a.pdf)、[PyVRP公式0.12.0 API](https://pyvrp.github.io/v0.12.0/api/pyvrp.html)、本調査 `probes/scale_probe.json`。容量216PE、先当たり102秒、帰庫32400秒は研究上の仮定である。

# ポスター用記述案

単一車の検証から、単一拠点の複数車両への拡張を設計した。主条件は5台500先・10台1,000先、20台2,000先は拡張条件とする。30台3,000先は実運用規模として保留し、合成負荷の上限試験に限定した。古典ソルバーの合成3,000先で実行可能解を確認したが、大田区道路OD・量子候補との同規模比較は未実行である。計画時間60・300・900秒は研究上の感度分析であり、実運用の締切ではない。

注：営業所の配備台数、同時計画台数、荷物個数、配送停車地点数を区別する。実運用値の参照は上記丸運・松戸資料。量子優位性や地域配送改善の実証を示す記述ではない。
