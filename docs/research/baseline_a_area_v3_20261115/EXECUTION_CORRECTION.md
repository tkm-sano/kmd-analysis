# 実行入口の修正と再確認

最初の `a_area_v3_20261115_selected_checks01` はS1の2試行で `NameError: ROOT is not defined` を記録した。計画生成前の入力段階であり、D・W・採用可能Tはnullである。S2第1試行の依存ライブラリ準備中に親と子を停止した。記録は上書きしない。

原因は追加モジュール `area_program.py` で既存入力ルート定数ROOTのimportが欠けていたことである。ROOTを既存programモジュールからimportし、実行入口から入力ルート解決・計画生成・結果保存・全生成物hash検証までを通す回帰テストを追加した。アルゴリズム、校正・選択結果、運行制約、需要・OD・計時境界は変更していない。

修正後は別出力 `a_area_v3_20261115_selected_checks02` に、登録済みのS1〜S3各2回を再実施する。未採択区域候補の診断は当初の各1回のみとする。失敗を除外して成功率を見せるものではなく、最終報告に最初の失敗と再確認を併記する。追加した試行は不具合修正の検証であり、本実験・追加需要・モデル再校正ではない。
