# 段階1〜7：A区域モデルv3の事前固定手順

2026-11-15。ユーザーは段階1〜7の実施を指示し、実績照合は公開資料に限定すると回答した。新しい方式は研究候補であり、京浜事業者の実方式として確定するものではない。RQ・仮説・A2・共通運行値・需要・道路・B/C/D・READMEは変更しない。

## 目的・分割

前回の最近隣検証で観測した区域への再進入の差を踏まえ、小区域を優先する訪問順を検討する。前回の30ルートとpilot2ルートは設計上の診断に既知であり、新しい独立検証には再利用しない。

校正用は既知拠点のうち前回使用した拠点日を除く最大6拠点、独立検証用は前回evaluationおよびpilotで使っていない最大6拠点とする。各拠点最大3日、各日最大2routeをメタデータhash順で選ぶ。最大36＋36routeである。両集合は拠点単位で分離し、前回の全拠点日を除外する。全IDとデータhashを先に保存する。公開のofficial evaluationファイルを今回の校正にも用いるため、競技の公式train/testの区分を維持した検証とは呼ばず、独自の厳格な拠点分割と明記する。

データ数・入力適格性・欠損による不足を補う再抽選は行わない。前回の成績やB/C/Dの性能で拠点を選ばない。都市が同じ拠点もあり、異なる国・大田区への外的妥当性は別である。

## 規則・校正

入力座標をデポ基準の局所平面に写し、最長軸の中央値で再帰分割する。最大葉サイズ6/12/24地点を候補とする。区域ラベルは各入力から自動生成し、実績順や公開zoneラベルを本体候補に渡さない。

次地点は有向費用の最近隣を原則とし、同一区域に未訪問地点がある場合、その最寄地点の費用が全体最寄費用の1.5倍/3倍以下なら区域内を優先する。上限なしも極端な候補として固定する。有限倍率なら必要に応じ区域外へ出て再進入を許す。始点はデポ、同値は地点IDである。入力上の全地点をちょうど1回並べる。

9候補に加え、元の最近隣をそのまま選択可能な対照に含める。新方式の採用を強制しない。校正損失は `(Amazon score + |既知zone再進入率−実績の率| + |log(公開行列の移動時間比)|)/3` の拠点日平均である。3項と等重みは研究上の適合基準であり、実務の効用やRQのJではない。最低損失を選び、1e-12以内の同点は単純なNN、次に小さい葉容量・弱い区域優先を選ぶ。

最良の区域候補も校正段階だけで固定し、NNが総合選択された場合にも診断に残す。選択モデルと全検証候補の順序hashを保存してから検証実績を評価する。事後にパラメータや損失の重みを変更しない。

## 独立検証・区域情報の依存

NN_time、選択自動区域モデル、最良区域モデル、同パラメータで公開zoneを与えた診断、座標距離へ投影した診断、NN_geo、実績参照を報告する。公開zoneを与える診断は大田区でそのまま使える方式ではない。主比較は選択モデルの損失−NN損失とし、拠点を単位とする5,000回bootstrapの記述的95%区間を出す。上端<0ならこの標本での改善を支持するが、実務との同等性を証明しない。

十分な根拠ある同等性許容幅は未取得でありnullを保つ。任意の10%等で代表性PASSを出さない。区域再進入・有向arc・Kendall・推定移動時間も併記する。Amazonは公開履歴平均時間の行列であり、現行A2の道路距離を直接検証したとは扱わない。

## 全体計画への接続・動作確認

校正で固定した選択モデルを用い、車両への初期角度割当・有限境界調整は既存A2規則を共用する。各車両の全担当先の訪問順だけを新規則へ置き換え、その後容量60で最大2便へ分割する。FCFS、全時刻、共通検査、独立再計算は同じ定義とする。B/C/Dの最終計画・完成器を流用せず、違反時の自動修復を行わない。

S1〜S3は凍結需要全件と既存Route版入力を用い、各2回の上限付き動作確認を行う。各試行は計画処理180秒・全プロセス300秒以内とする。Aは4コア利用可能枠内の1コア、native1threadで実行する。共通ライブラリ準備と出力をT外に別記し、入力・モデル読込から二重検証と指標一致までをT_programに含める。これを本実験・独立需要反復・正式T基準測定とは扱わない。

## 段階7の判定

公開資料だけで、対象/類似ToC拠点の割当・便・走行距離・帰着・ready・積込開始終了の対応を探索する。地域や業務が異なる値を単一実績に合成せず、模擬配送、実際の配送、推計、仮定、幹線待ち、路側駐車を区別する。未取得なら未取得と記録し、代表性FAIL/CONDITIONALと主比較採否を確定する。

段階7の調査・判定を完了することと、代表性PASSを得ることは別である。必要な証拠がない場合にも、それをもって採用を可としない。事業者への連絡、有料サービス、commit/push、本実験は行わない。
