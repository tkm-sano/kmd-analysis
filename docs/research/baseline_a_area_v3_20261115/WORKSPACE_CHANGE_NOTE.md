# 開始時から検出した既存ファイルの変化

保全監査[PRESERVATION_CHECK.json](PRESERVATION_CHECK.json)では、開始時にhashを記録した139ファイルのうち138ファイルが一致し、1ファイルの変化を検出した。HEADとREADMEは不変である。

対象は `src/kmd_toc/dwt/experiment.py` である。開始時hashは `827723091cdbbbe4857da47d5d8455ccdd6bb855449e170e26791bb65990667d`、検出時hashは `f732d7468d6c9e1ae076506d9e7af7526c764183c600900f6f10a3e0ae5776e3`、検出時のmtimeは2026-11-15T03:33:09.645422Zであった。

本作業の編集対象は新規A候補・CLI・設定・テスト・研究記録であり、この既存DWTファイルの編集を行っていない。変更主体は未確認である。現在の内容を保持し、開始時のhashへ戻す操作は行わない。「開始時の139ファイルが全て不変」という保全判定にはしない。監査コマンドはこの差を検出したassertionで非0終了しており、記録を隠していない。

最初の失敗実行、修正後の選択NN確認、区域候補診断の各REGISTRATIONは、いずれも変更後の同じhashを記録している。最初の保存snapshotと現在内容も一致する。従って、完了済み選択NN確認の `SOURCE_STABILITY.unchanged=true` と、開始時からの1件の差の検出は矛盾しない。前者は各実行の開始〜終了の不変、後者は作業開始時との比較である。Aの計画計算はDWT experimentの実行関数を使わず、B/C/Dの計算は実施していない。

最終監査ではこの差を明示し、各実行中のソース不変と、共通入力のhash確認を別に判定する。保存済みsnapshotにより、実行に使った版を再現できる。
