# 段階7：公開資料の追加探索記録

2026-11-15に公開情報だけを探索した。地元・対象業務との適合を優先し、京浜トラックターミナル、大田区、東京、国内類似拠点、国外公開データの順に資料を評価した。前回の公式4資料・地元事業者・国内荷待ち事例は旧原本を保持し、今回の追加資料を別保存した。

探索語群は「京浜トラックターミナル 宅配 配送 実績 距離」「大田区 宅配 配送 実証 走行距離」「宅配ナビ 22 クリーニング」「宅配 営業所 積込 待機 バース」「宅配 配送計画 作成 時間 実績」「last mile delivery public actual routes loading waiting GPS dataset」等である。事業者、JILS、行政、学術論文、データ提供者を優先した。検索は網羅的な系統レビューではない。

地域適合性の高い追加結果はSGシステム/JILSの2017報告書である。PDF pp31–32と図を照合し、大田区の22地点はクリーニング店を仮定した模擬走行であることを確認した。ToC実績の適格性とは分けた。

積込待ちの候補として大阪労働局・鴻池/ダイキンの事例、ヤマト総研の予約納品を確認した。いずれも対象の出発ToC積込に対応せず、Wの参照値に使わない。経産省の報告例PDFは403で未取得であり、検索抜粋の数値を実績扱いしない。

国外ではAthens医薬品3PLの論文と公開データ説明を確認した。実注文と生成行列を区別し、実運行の割当・訪問順・待機をそろえる資料として不採用とした。ModenaのTRACE GPSデータは公開ページを閲覧できたがAPI/CSV先頭の直接取得が403であった。Web previewも項目本文を表示しなかった。追加のWeb直接取得ではorders CSVヘッダと本文を閲覧でき、車両ID・出発/到着位置・配達時刻・時間窓等は確認した。明示的なload_ready/load_start/load_endは閲覧ヘッダに見当たらない。GPS CSVはWebの4MB超の容量上限で未取得である。データ一式の列が欠落しているとは断定しない。個人を含む行内容を研究報告へ転載せず、必要な項目の確認に留めた。

検索で現れた合成SQLサンプル、路側のloading zone/駐車滞在、幹線の荷待ち、施設総取扱量、一般的な原単位や想定例は、拠点ToC実績の代替にしない。異なる研究の距離・待ち・人手Tを合成しない。

この範囲では、対象/国内類似ToCの割当・便・実距離・ready・積込開始終了と計画工程をそろえる適格な公開資料は取得できなかった。段階7の探索と採否判定は終了するが、適格実績との数値照合という研究上の要件は未達成である。公開資料限定の条件を守り、外部への依頼や送付は行っていない。
