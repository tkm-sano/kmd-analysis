# 専門家インタビュー回答票

**テンプレート版：1.0.1／2026-10-21**

[プロトコル](EXPERT_INTERVIEW_PROTOCOL.md)の面接・記録を補助する空の回答票である。対象事例・説明する関係ごとに必要な表を複製して使う。全欄を埋めることを要求しない。空欄をゼロ、不支持、不存在に変換しない。記入できない場合は、説明なし、質問未実施、専門外、資料未確認、判断不能、非該当を区別する。匿名化した参照だけを用い、実際の個人情報・逐語録を公開リポジトリに保存するための票ではない。

## 1. 比較する事例

| 項目 | 記入欄 |
|---|---|
| 面接の記録参照・日時・タイムゾーン | |
| 匿名化した回答者 | |
| 専門範囲・担当範囲 | |
| 対象図・図の版 | |
| 使用したプロトコル版・SHA-256 | |
| 使用した回答票版 | |
| 研究・開発・運用事例、その時期と範囲 | |
| 従来方式 | |
| 量子方式（具体例が未確認ならその状態） | |
| 共通条件：配送先・期限・車両数・担当需要等 | |
| 異なる条件 | |
| 各配送先での配達完了状態・完了時刻の記録参照 | |
| 走行時のバッテリー消費電力量の対象区間・計測境界・記録参照 | |
| 計画上・実際の旅行時間、配達作業時間、計算時間の定義 | |
| 録音・文字起こしの時刻／行と書込み図への参照 | |
| 回答できない項目と理由 | |

面接実施時に、参加、録音、図への書込み、引用の同意をそれぞれ記録する。チェックされていない状態を同意と解釈しない。

| 同意の対象 | 確認した状態 | 記録の参照・条件 |
|---|---|---|
| 参加 | [ ] 同意あり　[ ] 同意なし　[ ] 未確認 | |
| 録音 | [ ] 同意あり　[ ] 同意なし　[ ] 未確認 | |
| 図への書込み | [ ] 同意あり　[ ] 同意なし　[ ] 未確認 | |
| 引用 | [ ] 同意あり　[ ] 同意なし　[ ] 未確認 | |

提示による影響を追跡するため、実際の順序を記録する。

| 順序・時刻 | 提示した前提・図・具体例・質問・追問 | 版・図上の位置・記録参照 |
|---|---|---|
| | | |

## 2. 仕組みの違い

| 項目 | 記入欄 |
|---|---|
| 図のどの関係についての説明か | |
| 従来方式の処理・得られる情報・判断 | |
| 量子方式の処理・得られる情報・判断 | |
| 異なる部分 | |
| 共通する部分 | |
| 扱う条件を増やすことによる違い | |
| 同じ条件を量子方式で解く追加的な貢献 | |
| 追加的な貢献が未確認の部分 | |
| 電池に関係する基礎技術 | |
| その技術における量子計算の役割と従来との差 | |
| 関係する性能指標（改善量が不明でも記録する） | |
| 説明された内容・原発言の参照 | |
| 研究者の要約・解釈（原発言と分離する） | |

数値が示された場合のみ、次の表を使用する。数値回答がないことを回答の不備としない。

| 項目 | 記入欄・選択肢 |
|---|---|
| 数値・範囲・単位 | |
| 対象の性能指標・量の定義 | |
| 数値が表す対象 | [ ] 材料の物性・特性　[ ] 電池セルの性能　[ ] 電池パックの性能　[ ] その他　[ ] 不明 |
| 数値の性質 | [ ] 実測値　[ ] 計算結果　[ ] 開発目標　[ ] 不明 |
| 従来の比較値・基準・比較条件 | |
| 数値の解釈に必要な試験条件 | |
| 量子計算による寄与の根拠／通常の開発成果との区別 | |
| 出典と資料確認の状態 | |

重量エネルギー密度を記録する場合は、単位（Wh/kg）と、電池セル・電池パックのどちらの値かを明記する。材料の物性の計算値と実験で確認された材料特性を区別する。モデル上の仮定値を専門家が示した実績へ置き換えない。

## 3. その違いは次の判断・運用へ伝わるか

| 項目 | 記入欄・選択肢 |
|---|---|
| 図にある関係：何の違いが、次のどの判断や状態に関係するか | |
| 対応する成果 | [ ] 定時配達率　[ ] 走行時のバッテリー消費電力量　[ ] 両方　[ ] 成果につながるかは未確認 |
| 次の判断・運用へ伝わる仕組み | |
| 成立条件 | |
| 不成立条件・例外 | |
| ほかに考えられる理由（代替説明） | |
| 計画作成の改善が関係する条件 | |
| 計画作成方法を変えても運用上変えられない条件 | |
| 交通条件と適用範囲（時間帯別の交通混雑・信号・通行規制・迂回路・代替経路等） | |
| 計画に用いた交通情報と実際の交通状態の区別 | |
| 容量を一定にした電池パックの軽量化として扱える範囲 | |
| 録音・文字起こし・図上の位置の参照 | |

図にある関係が成り立つかについて、説明された状態（接続の状態）を選択する。この選択は専門家の説明の状態であり、研究者による独立した実証判定ではない。

- [ ] 具体的事例で確認したと説明された
- [ ] 仕組みは説明されたが成立は未確認
- [ ] 当該条件では成立しないと説明された
- [ ] 判断不能

記録できない項目がある場合の理由は、該当項目とともに記す。

- [ ] 説明なし
- [ ] 質問未実施
- [ ] 専門外
- [ ] 資料未確認
- [ ] 非該当

## 4. What-if：技術が変化しても成果が変わらない場合

What-ifは、仮想条件を示して説明が成り立つ範囲を確かめる質問である。

| 項目 | 記入欄 |
|---|---|
| 提示した仮想条件・質問、その順序 | |
| 技術・計画の何が変わると仮定したか | |
| 変わらないとした成果とその定義 | |
| 説明された不成立条件・例外 | |
| ほかに考えられる理由・見分けるために必要な情報 | |
| 先に述べた成立条件の修正 | |
| 仮定自体が不適切である場合の理由 | |
| 対応する実例の所在（説明された場合のみ） | |
| 原発言の参照／研究者の解釈 | |

What-ifの状態を記録する。実例の存在を研究者が独立に確認したかは第5区分へ別に記す。

- [ ] 対応する実例がある
- [ ] 仮想的な推論
- [ ] 複数の説明が残る
- [ ] 仮定自体が不適切
- [ ] 判断不能

必要な範囲で、次の区別を記録する。

| 区別する内容 | 記入欄 |
|---|---|
| 利用できる配送計画がない／配送計画案を採用しない／計画の違いが実際の走行に反映されない | |
| 配達完了時刻も不変／時刻は変化したが定時配達率のみ不変 | |
| 期限内に完了した配達先の一致・不一致・不明 | |
| 走行時のバッテリー消費電力量の増減が相殺された場合／記録不足 | |
| 配達の未完了／記録の欠測 | |

|---|---|---|---|
| | | | |

| 項目 | 記入欄・選択肢 |
|---|---|

## 6. 図の修正・確認

| 対象図・版・図上の位置 | 専門家自身が提案した修正 | 研究者が提案した修正 | 記載との一致の確認・訂正内容 | 原記録・書込み図の参照 |
|---|---|---|---|---|
| | | | | |

記載との一致の確認状態を記録する。

- [ ] 記載との一致を確認した
- [ ] 記載を訂正した
- [ ] 未確認

| 項目 | 記入欄 |
|---|---|
| 確認した記載の範囲と確認時刻 | |
| 訂正前の記載・訂正後の記載 | |
| 専門家の提案と研究者の採否判断を区別するための分析記録参照 | |
| 図にある関係のうち未確認のもの・確認できなかった理由 | |

専門家の確認は「研究者の記載が説明と一致しているか」の確認である。因果関係の実証、研究者による面接後の改訂モデル（M1）への採択、倫理承認を意味しない。本票への書込みだけで面接前モデル（M0）の正本を更新しない。採否は[分析ガイド](EXPERT_INTERVIEW_ANALYSIS_GUIDE.md)に従って別に判断する。
