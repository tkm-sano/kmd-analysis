# 二目的比較の実験設計

2026-11-17の最新研究判断に基づく。正本は[二目的研究方針](DW_RESEARCH_POLICY.md)と[現行設定](../../configs/toc_delivery/dw_policy_20261117_v1.json)。旧本文は[変更前の保存版](../audits/dw_policy_20261117_v1/before/docs/research/DWT_EXPERIMENT_DESIGN.md)に保全する。

研究範囲はD/Wの性能差とトレードオフである。同じ凍結需要・Route OD・共通物理制約からA/B/C/Dを比較し、量子寄与の補助対照にD_CLASSICAL_REPLACEMENTを用いる。

既存75試行（3規模×5条件×5外側試行）は予備データとして保持する。新方針に基づく再分析は探索的であり、これを本実験の事前登録に読み替えない。5反復を精度や検出力の十分性の根拠としない。

今後のアルゴリズム終了は有限作業量規則を継承する。B/C/Dは内部4枝、各1コア・native1threadで、手法間は逐次。内部枝は外側1試行に含む。全枝の成否・seed・PID・affinity・D/W・量子処理を保存する。有限ループ上限を変更して品質を調整する作業は今回行わない。

総合仮説の評価方法、主比較family、要求精度、固定試行一覧は未決定で、本実験はHOLD。旧の時間予算グリッド・計算時間の精度・T参照値・旧Jを継承しない。既存結果や需要を上書きしない。
