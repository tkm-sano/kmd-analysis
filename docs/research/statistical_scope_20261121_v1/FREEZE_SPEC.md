## FREEZE：比較・指標・統計

Aは行政統計外部参照、Bは従来型、Cは古典最適化、Dは量子・古典ハイブリッド。各規模でA対B/C/D、B対D、C対Dの5組を共通構造で保持する。

主要指標はD［km］・W［分］だけ。Wは全活動便のΣ(load_start-ready)/60という既存総積込待機で、平均へ変更しない。I_dualはD/Wから導く両立改善指標。T・CPU・メモリ等は補助記録に保持し、主要図の第三指標にしない。

B/C/Dの有効外側試行についてJ、平均、標本SD、中央値、Q1、Q3、IQR、最小、最大を記録する。

```
s = sqrt(sum((x_j-mean(x))**2)/(J-1))
MCSE(mean(x)) = s/sqrt(J)
```

J<2のSD/MCSEは未定義。観測SD=0は0のまま保存するが、真の分散0や決定論の証明としない。独立性が登録・根拠で確認できる場合にだけ単純MCSEを計算する。独立性未確認でも観測値の記述SDを出せるが、独立JやMCSEを確認済みにしない。

四分位数の実装はソフトウェア間の曖昧さを避けるため、並べたJ値の位置 `(J-1)*p` の線形補間（type 7）に統一する。文献がこの補間方式を唯一の定義と指定したという意味ではない。欠測・非有限値を0にしない。失敗・不可行・未完了・欠測・未開始・除外理由を全予定外側試行の分母で報告し、有効値の記述統計は成功条件付きであることを表示する。失敗に対する性能罰則や無条件性能の推定対象を自動採択しない。

## FREEZE：改善・両立

```
delta_D = D_Y-D_X; delta_W = W_Y-W_X  # 負が改善
r_D = 100*(D_X-D_Y)/D_X; r_W = 100*(W_X-W_Y)/W_X
I_dual(X|C) = 100*min((D_C-D_X)/D_C,(W_C-W_X)/W_C)
```

相対率は基準値>0の場合だけ定義する。I_dualはD_C/W_Cの両方が正の場合だけ定義する。分母0へεを加えたり0%で補完しない。I_dual>0/0/<0の解釈は既存定義を維持する。DとWの双方の厳密減少割合は、正当な比較単位がある有効な同一計画組に対して数え、分母と欠測を明示する。分母0でも絶対的な同時減少条件自体は定義でき、I_dualの未定義とは分ける。

B/D・C/Dの対応差は、結果を見る前に登録した共有確率要因などの根拠と一対一対応がある場合だけ作る。同じ需要・seed整数・repeat番号・事後の相関だけでは対応としない。SDとMCSEは対応差そのものから計算する。独立2群で対応がなければ平均差は出せるが、任意の行同士や直積から改善分布・改善SD・両立割合を捏造しない。独立2群の平均差のMCSEは `sqrt(s_X^2/J_X+s_Y^2/J_Y)` とし、両群の独立性が確認できない場合はHOLD。

平均の差と試行差の平均、平均値を代入したI_dualと試行別I_dualの平均を区別する。C参照の割当根拠を記録し、共通の確率的Cを複数試行で再使用した派生値のMCSEを無条件に独立式で計算しない。固定C参照を使う場合は決定論の独立根拠と固定参照条件付きの推定対象を明示する。Cを自分自身と比べたI_dual=0は基準線にし、疑似反復箱を作らない。AをC分母へ代入しない。

Aに試行分布・SD・MCSEを付与しない。各指標について単位、測定範囲、時点、地域、集計対象の整合と根拠を確認したときだけ絶対差・相対差を計算する。未確認なら比較HOLD、参照資料の数値・意味だけを残す。Pと配送先数、行政運行Uと研究便を自動同一視しない。

## FREEZE：図表

D/W/I_dualの箱ひげ図は規模別・方式別。箱Q1〜Q3、中央値、IQR。ひげは `[Q1-1.5*IQR, Q3+1.5*IQR]` に含まれる最小／最大の実観測値、外側は外れ値。外れ値を削除しない。Jを表示し、ごく少数値も生データ点として見えるようにする。ノッチCIは使わない。

Aは比較可能性を確認した指標の参照点／基準線のみ。SEM/MCSE/95%CIを主要エラーバーへ使わず、有意差記号・p値を表示しない。エラーバーの重なりから有意性を解釈しない。
