# D・Wの図表仕様

2026-11-17の最新研究判断に基づく。正本は[二目的研究方針](DW_RESEARCH_POLICY.md)と[現行設定](../../configs/toc_delivery/dw_policy_20261117_v1.json)。旧本文は[変更前の保存版](../audits/dw_policy_20261117_v1/before/docs/research/DWT_7_FIGURES_SPEC.md)に保全する。

既存ファイル名はリンクの互換性のため維持する。旧7図契約は終了し、現行は次の4図である。

|図|内容|
|---|---|
|1|Dの観測値と手法差。単位km、S1〜S3別|
|2|Wの観測値と手法差。単位分、S1〜S3別|
|3|同じ計画のD–W散布図と観測された二次元非支配点|
|4|登録・開始・採用・失敗・未完了・未実行の件数と検証済み計画取得率|

Tの軸、点サイズ、色、時間スライス、品質対時間曲線、旧Jの図を廃止する。点サイズは一定で、色は手法を表す。三規模は別パネルにし、異なる入力を同じ支配判定へ混ぜない。D/W最小値を別試行から結合しない。

各図に登録数、採用数、M=1、入れ子需要、探索的再分析であることを明記する。Aの繰返し値を品質分布の独立標本として描かない。失敗を0の座標へ置かない。非支配点を真の最適解、平均点を実在計画と呼ばない。

95%CIが算定不能なら理由を表示する。箱ひげのひげを95%CIと呼ばない。現在の分析が出力するのは図の元となるD/Wデータと非支配IDであり、本実験の図や未観測の曲面を生成しない。J_DWの図は定義採択までHOLD。
