# 現行図表仕様：箱ひげ・平均±1標本SD

2026-11-21の[統計Freeze](statistical_scope_20261121_v1/FREEZE_SPEC.md)を適用する。D/W/I_dualを規模・方式別に箱ひげと平均±1SDで表示する。箱Q1〜Q3、中央値、ひげは±1.5IQR範囲内の最端観測値、外側は外れ値。Jと少数の生観測を明示し、外れ値を消さない。四分位は位置(J−1)pの線形補間に固定した。

改善量のSDは正当に対応した試行差から計算し、方式SDを流用しない。対応がなければ平均差の点のみで、SD不明を0にしない。Aは比較可能な参照点・線だけで、箱やSDを作らない。SEM・MCSE・95%CI・有意差記号・p値は主要結果図に使わない。MCSEとprefix箱は内部J評価へ分離する。エラーバーの重なりから有意性を解釈しない。

ファイル名の旧「7」は歴史的な名称で、新しい図数を7へ制限しない。Tは補助記録のみ。以下は旧版の履歴。

# 現行図表の表示上の留意事項

2026-11-20更新。この文書は現行案内であり、研究仕様の正本ではありません。[研究仕様1〜7（凍結v1）](../frozen/配送計画最適化_評価指標と実験条件_1-7.md)と[追加運用仕様FCFS_v1](FCFS_OPERATING_POLICY_V1.md)を参照します。数式・数値・未決定事項をこの案内から新たに決定しません。更新前の案内（保全資料）は保全しています。


旧ファイル名のDWTを理由にTを第三目的へ戻さない。現行の主要指標はD［km］・総積込W［分］・I_dual［%］、T［秒］は補助指標。平均荷待ちをW軸へ代用しない。

- 規模、需要/最適化seed、運用版、評価版、計算予算、単位、試行状態を明示する。
- FCFS_v1で生成した結果、FCFS適合を再確認した旧結果、固定経路の変換結果を区別し、混在させない。
- Aは異なる資料の外部参照で、同じ実績計画のD/W点にしない。荷待ち統計と研究積込Wの違い、P/U換算を示す。
- I_dualの分母0・未実装・欠測を0%で埋めない。一方のみ改善を両指標改善と表示しない。
- 反復や信頼区間が未設計の図を母集団上の支持としない。テスト件数・内部枝を試行数へ加算しない。

旧図の軸名を付け替えて新仕様の結果へ転用しない。過去の図表・結果は履歴として保全する。新しい図表の作成や採用する統計手法を今回決定せず、本実験HOLDを維持する。
