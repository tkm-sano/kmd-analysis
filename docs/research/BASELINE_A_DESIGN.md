# 外部参照ベースラインAの現行案内

2026-11-20更新。この文書は現行案内であり、研究仕様の正本ではありません。[研究仕様1〜7（凍結v1）](../frozen/配送計画最適化_評価指標と実験条件_1-7.md)と[追加運用仕様FCFS_v1](FCFS_OPERATING_POLICY_V1.md)を参照します。数式・数値・未決定事項をこの案内から新たに決定しません。更新前の案内（保全資料）は保全しています。


Aは経路・車両割当・訪問順・積込計画・計画作成時間Tを持たない。FCFS対象はB/C/Qであり、Aは対象外。正本第5節の公開統計と換算仮定を分ける。

|参照|仕様|留保|
|---|---|---|
|距離|D_A_ref=0.58P km|Pは宅配便の荷物個数。幹線輸送を含まない全国数社の参照値|
|2025年度荷待ち|W_A_ref=60U 分|Uは統計の運行に対応すると仮定する換算回数。研究の1便と自動同一視しない|
|2020年度参考|W_A_2020_ref=94U 分|別年度の補助参照。表示n=315を荷待ち発生運行のみの標本と断定しない|

「1配送先＝宅配便1個」を換算仮定として置く場合に限り、S1/S2/S3の距離参照は580/1160/2320kmとなる。これは重量kgや実荷物個数を車両容量へ校正したという意味ではない。研究の便当たり上限は最大60配送先である。

統計荷待ちと研究の総積込待機Wは測定対象が異なる。異なる資料の距離・待機を一組の実績計画にせず、AをI_dualの比較基準Cへ代入しない。参照値へ合わせた校正も行わない。

出典は正本と同じURLを案内する。今回新たな公開値の採用・再推計は行わない。

- [国土交通省2015年資料、PDF4頁](https://www.mlit.go.jp/common/001102289.pdf)：0.58km/個。
- [2026年7月10日公表PDF](https://www.mlit.go.jp/report/press/content/002011131.pdf)：2025年度60分、2020年度94分と表示n。
- [公表ページ](https://www.mlit.go.jp/report/press/tokatsu02_hh_000084.html)。

既存 `cargo_wait_v2.reference` は旧版の0.58N・60分/運行のAPIを保持する。明示Uによる60U/94Uの総量換算や指定出典とのメタデータ統合等に未実装・差異が残る。文書更新を実装修正済みと解釈しない。[凍結時監査](../../reports/RESEARCH_FREEZE_AUDIT_20261120.md)を参照する。

旧A_rule_v1・A_human_v1・A-area等は別の経路生成手法/契約の履歴であり、現行Aへ流用しない。過去結果と出典を削除しない。
