## 4. 分散と必要数の算定

完全な均衡データの対応差を Δ_ij=X_Dij−X_Cij とする。独立family、条件付き独立反復、有限分散を仮定し、Δ_ij=μ+b_i+e_ij、Var(b_i)=σ_b²、Var(e_ij)=σ_w²とする。

SE(平均Δ)≈sqrt(σ_b²/n+σ_w²/(nr))。需要差が大きいと、rだけを増やしてもσ_b²/nは減らない。

ANOVA確認式は MSW=Σ_iΣ_j(Δ_ij−平均Δ_i)²/[n(r−1)]、MSB=rΣ_i(平均Δ_i−全平均Δ)²/(n−1)。σ_w²の点推定はMSW、σ_b²はmax(0,(MSB−MSW)/r)。採用推定は非負REMLと整合を確認する。r=1では2分散を分離できない。失敗のあるデータへこの完全データ式をそのまま適用しない。

目標平均CI半幅hと、最小の意味ある差δは別の入力である。q(r)=σ_b²+σ_w²/r として、初期近似は

\[
n_h(r)=\left\lceil\frac{1.96^2 q(r)}{h^2}\right\rceil,\qquad
n_\delta(r)=\left\lceil\frac{(z_{1-\alpha/2}+z_{1-\beta})^2q(r)}{\delta^2}\right\rceil.
\]

α=.05、β=.20は設計値。nは独立需要事例数でありnrではない。h/δの単位はそれぞれkm・分・秒の該当指標に合わせる。小標本ではt臨界値とn−1自由度で反復し、実際に採用する検定・失敗モデルで被覆率/検出力を将来検証してから決定する。式の正規近似だけで80%達成を保証しない。[NISTの標本数設計](https://itl.nist.gov/div898/handbook/prc/section2/prc222.htm)を参照。

平均の式は中央値・パレート集合・可行率の精度を直接保証しない。それぞれの追加条件から必要数を評価し、登録された必須条件について最大を採る。異なる目的で得たn/rを別々の都合のよい結果として混合しない。

## 5. 分散推定の不確実性

点推定だけで本番nを決めない。完全・正規・均衡モデルなら、予備n0/r0でν_b=n0−1、ν_w=n0(r0−1)とし、以下の同時上側包絡を監査に使える。

U_B=ν_b MSB/χ²_.025,ν_b は θ_B=σ_w²+r0σ_b² の上側限界、U_w=ν_w MSW/χ²_.025,ν_w はσ_w²の上側限界。Bonferroniにより両上限を同時に満たす確率は少なくとも95%（このモデル内）。σ_b²≤U_B/r0なので保守的に q_U(r)=U_B/r0+U_w/r を使い、点推定版と保守版の必要数・費用を並べる。二重に内分散を見込む保守性も明記する。

正規・均衡仮定が崩れるとこのχ²被覆は使わない。非負境界に対応したprofile likelihoodの校正、または需要family単位の再標本化・将来の統計モデル上の検出力評価で不確実性を調べる。反復を無条件に二重bootstrapして内分散を二重計上しない。観測分散0や少数成功を真の分散0・必要n=1の根拠にしない。上側分散を識別できない場合は本番数HOLDとする。

失敗がある場合、主要な条件付き差の比率推定・影響量で計画分散を求める。単に成功件数をrに代入して需要内相関を消す扱いは禁止。具体式は[統計プロトコル](DWT_STATISTICAL_PROTOCOL.md)に固定する。

## 6. nとrの選択手順

1. 各規模・条件・主要差/指標について、間/内分散と不確実性、成功率を得る。S1分散をS2/S3の既知分散へ流用しない。
2. 承認済み計算上限から有限のr探索範囲を定め、r=1,2,3,…を列挙する。5を既定にしない。
3. 各rで平均・対応差CI、主比較power、中央値の必要精度、可行率、attainment精度の必要nを算定する。複数主要比較へ変更するなら事前にfamilyを列挙し、保守的Bonferroni設計＋Holm解析等へ変更する。
4. n(r)の整数切上げ、有限標本補正、分散上側包絡、失敗・分布感度を適用し、費用とRSSを算定する。追加反復による分散減少はσ_w²/[r(r+1)]で、需要数を増やす場合の効果と比較する。
5. 全必須基準を満たす候補の中で総費用最小を採用。同費用なら独立需要数nが大きい候補を優先。候補なしはHOLDであり、達成済みと記載しない。
6. 真に決定論的な全パイプラインでD/Wが固定なら品質反復r_Q=1を認める。一方、T計測の反復r_Tは別に決める。CWだけが決定論的でも完成器・時間打切りが変動すればB全体を決定論的としない。
7. n/r、原データID・seed、停止規則をFreeze 2に保存。予備family/seedを本番から分離し、予備の有利な観測を本番へ選別追加しない。

参考の費用構造 C(r)=n(r)(c_I+r c_R) では、分散が既知・連続r・追加制約なしなら r*=sqrt(σ_w² c_I/(σ_b² c_R))。これは整数設計の目安であり、採用値ではない。σ_b²=0、失敗、複数指標、資源上限があれば直接使わない。

## 7. 資源評価と採否

規模sの費用は C_s=Σ_c n_s Σ_m r_scm c_scm + n_s c_A,s + 対照費用 + 共通準備 + setup/export/監査費用。cは**将来の正式予備で取得した全試行コスト**で、失敗経過も含む。ε・τの条件数を隠さない。単に予算τを平均実測Tと同一視しない。ソルバー同時実行はせず、1コア共通条件を基準にする。

OD取得/索引構築はT_programから除外するが、研究全体の予算には含める。ピークメモリは逐次なら各工程の最大と共通常駐メモリ、並列へ変える場合は同時常駐量・CPU競合を別途評価する。旧S1の保存時間/RSSは参考であり、正式予備の実測として費用表を埋めない。

資源不足では、主比較を維持→探索的条件数を減らす→精度/主張範囲を再評価→限界を記録する。h/δを実験後に緩めて十分だったと主張しない。S2主ケースが未達ならS1を自動的に確認的主結果へ昇格させず、主計画未完了と報告する。
