# D・Wの必要反復数設計

2026-11-17の最新研究判断に基づく。正本は[二目的研究方針](DW_RESEARCH_POLICY.md)と[現行設定](../../configs/toc_delivery/dw_policy_20261117_v1.json)。旧本文は[変更前の保存版](../audits/dw_policy_20261117_v1/before/docs/research/DWT_SAMPLE_SIZE_PIPELINE.md)に保全する。

本実験の必要反復数は未決定である。Tの分散、TのCI幅、人手T参照、旧Jの分散、時間測定専用反復を品質精度の設計から外す。

1. J_DWを使うか、正規化・重み・推定対象・A/B/C全比較の支持規則を先に定める。
2. D[km]・W[分]の許容区間半幅、検証済み計画取得率の精度、主要比較範囲を定める。
3. 固定需要内の独立外側反復と独立需要family数を分け、成功条件付きの品質と失敗過程を考慮する。
4. 観測0分散では未知分散が未識別であると報告する。0を代入して必要反復数1や0幅CIを生成しない。
5. 本実験前に全試行一覧・seed・順序・停止規則を固定する。途中の有意差、勝敗、CI幅で追加しない。

実行管理の資源費用を確認する場合も、研究上の性能順位やD/W仮説の指標へ戻さない。既存75試行や内部4枝を新本実験の独立標本へ転用しない。新規需要生成はこの設計の一部として無断実施しない。
