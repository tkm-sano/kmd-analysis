# B/C/QのCPU条件と計時の未確定範囲

2026-11-20更新。この文書は現行案内であり、研究仕様の正本ではありません。[研究仕様1〜7（凍結v1）](../frozen/配送計画最適化_評価指標と実験条件_1-7.md)と[追加運用仕様FCFS_v1](FCFS_OPERATING_POLICY_V1.md)を参照します。数式・数値・未決定事項をこの案内から新たに決定しません。更新前の案内（保全資料）は保全しています。


共通の計算資源方針は手法内4プロセスの枝、各枝1コア・native1thread、手法間逐次。割当不足を黙って逐次へ落とさない。全枝のseed・PID・affinity・成功/失敗・量子呼出し・shots・計時を保存し、未選択枝の消費も隠さない。

4枝は同じ入力に対する内部探索で、4個の独立需要・統計試行ではない。shots、局所反復、候補数とも区別する。各枝が作る配送計画の積込規則は同じFCFS_v1で、最終候補も独立FCFS検証を通す。

共通Tの値、計時開始・終了範囲、準備/出力処理の扱い、全枝停止、期限時点の採択は未確定。既存の有限仕事量や保存wall timeを同一時間比較の正式契約としない。旧DのIPと新FCFS CPの計算費用を同条件として混ぜない。

正式全体Qランナーは未完成。FCFSの人工枝単位テストを4枝本実験の性能検証と呼ばない。[FCFS検証報告](../../reports/FCFS_V1_IMPLEMENTATION_REPORT_20261120.md)に実行範囲を記録している。本実験HOLD。
