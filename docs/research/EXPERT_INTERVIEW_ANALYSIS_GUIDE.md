# 専門家インタビュー分析・M0–M1改訂ガイド

**版：1.0.1／2026-10-21**

[プロトコル](EXPERT_INTERVIEW_PROTOCOL.md)を面接前モデルM0の正本とし、面接後の改訂モデルをM1とする。本書は一次記録の整理、RIQによる照合、根拠確認、改訂判断の規則と空の記録テンプレートである。面接結果・実際の原発言・M1は未取得／未作成であり、以下に架空の回答や判定を記入しない。本書も[M0登録情報](EXPERT_INTERVIEW_M0_MANIFEST.json)の固定対象である。

## 1. 一次記録の整理

面接を実施した後、同意条件に従って一次記録を管理する。公開リポジトリには実際の個人情報・逐語録を保存しない。保管場所・期間・アクセス権・撤回条件は面接前に確定する。

1. 面接で使用したプロトコル・図・回答票の版とハッシュ、匿名化した回答者、専門範囲、対象事例を確認する。
2. 録音がある場合は文字起こしと照合し、時刻・行番号を保持する。録音がない場合は、その制限と面接時記録の所在を明記する。研究者の要約を逐語引用に置換しない。
3. 研究者が提示した前提、図、具体例、質問、追問とその順序を原発言へ対応付ける。自発的説明と提示・追問への回答を区別する。
4. 原文と前後の文脈を保ったまま、対象の関係を検討できる単位を選ぶ。仮定・否定・留保を削らない。一つの発言が複数の関係に対応するときは、同じ原記録への参照を保持する。
5. 文献に基づく事前仮説、実際の専門家発言、研究者の解釈、独立資料、What-ifへの回答を別の記録として保持する。
6. [回答票](EXPERT_INTERVIEW_RESPONSE_TEMPLATE.md)の記載確認・訂正を一次記録と照合する。記載確認を経験的な因果効果の確認とは扱わない。

面接前に記入するのはM0と出典の情報だけである。面接前の説明を専門家発言欄へ移さない。パラメータ・変数・リンクの対応付けは研究者の分析作業であり、専門家に網羅的なモデル設計を求めない。

## 2. RIQの適用範囲

RIQ（Rigorously Interpreted Quotation Analysis）は、原発言の表現とモデル要素を対応付け、解釈過程を明示して整合・不一致を検討するために用いる。原著の対象は概念化後期の因果ループ図（CLD）である。本研究はその原文照合を条件付き因果関係へ援用し、以下の性質を分けて扱う。[原著・DOI](https://doi.org/10.1002/sdr.1701)

| 記述の性質 | 本研究で行う照合 | それだけでは認定しないこと |
|---|---|---|
| 処理順序・情報受渡し | 何を計算・伝達・判断するかを技術記述と照合する | 処理の順番だけによる因果効果 |
| 指標定義・算術関係 | 対象集合、単位、期限、固定条件、式を検査する | 定義・算術そのものの経験的効果 |
| 条件付き因果関係 | 原文中の表現・文脈とM0の関係をRIQで明示的に照合する | 専門家の説明だけによる量子技術効果の実証 |
| What-if回答（仮想条件についての回答） | 仮想条件、推論、対応する実例の有無を区別して記録する | 仮想的説明を経験的反証にすること |

4図全体を厳密なCLDと呼ばない。原著のループ・遅れ・極性の評価を全図に機械的に適用せず、形式を整えるためだけのフィードバックループや因果極性を追加しない。カテゴリ変数や訪問順へ一律に正負符号を付けない。暗黙の接続があると解釈するときは、原文にない前提と別の解釈を明記し、専門家が述べた事実へ変換しない。

本書の二軸判定・表形式・改訂規則は本研究の実施仕様であり、原著においてこの回答票や4図構成が標準化・検証されたとするものではない。書誌情報、参照した原著の箇所、未確認範囲は[プロトコル第10節](EXPERT_INTERVIEW_PROTOCOL.md#10-根拠資料と確認範囲)に集約する。

## 3. 二軸を分けた判定

第一の軸は「原文がモデルの説明と整合するか」である。第二の軸は「その説明の実際の成立が、どの証拠でどの範囲まで確認されたか」である。両軸を一つの支持点数へまとめない。

| 判定軸 | 記録する状態 | 注意点 |
|---|---|---|
| 原文とM0の照合 | 整合／不一致／条件限定／判定不能 | 同じ用語でも意味・対象・比較条件が違えば、直ちに整合としない |
| 成立を裏付ける証拠 | 専門家が事例で確認したと説明／独立資料の該当範囲を確認／モデル内の結果のみ／仮説・推論／未確認 | 排他的な一列の強弱尺度ではない。確認した資料・対象範囲・残る限界を併記する |

原文がM0と整合しても、量子技術の実際の効果が確認されたことにはならない。「専門家が確認したと述べた」と「研究者が独立資料を確認した」を分ける。文献から設定した事前仮説と専門家の説明が一致しても、それらが同じ資料に由来する場合は独立した証拠として二重計上しない。

## 5. 根拠照合

| 確認対象 | 照合する内容 |
|---|---|
| 研究・開発・運用事例 | 対象地域、配送内容、時期、技術成熟度、比較対象、共通条件と相違 |
| 計画作成 | 条件を増やした効果と、同じ条件で量子方式を使った追加効果。計算で得られた配送計画・取得状態、検証状態、現場で配送計画を利用できる時刻。計算終了、配送計画案の取得、採用、実行を区別する |
| 定時配達率 | 固定した評価対象、各配送先での配達完了状態・完了時刻・期限。配達先への到着と配達作業の完了、配達の未完了と記録の欠測を区別する。率が同じでも期限内に完了した配達先が同じとは限らない |
| 走行時のバッテリー消費電力量 | 同じサービス、区間、単位、駆動・補機の消費・受入回生、端子計測と成分集計の重複の有無。既存の回生・補機を除いた計算結果と区別する |
| 交通条件 | 計画に用いた情報と実際の交通状態。時間帯別の交通混雑、信号による停止・再発進、通行規制、迂回路・代替経路の有無。交通条件の一般的な影響と、従来方式から量子方式へ変更した場合の差が交通条件によって変わることを区別する。信号制御による交通変更へ拡張しない |
| 電池の数値 | 材料の物性・特性／電池セルの性能／電池パックの性能と、実測値／計算結果／開発目標を別々に確認する。単位、比較基準、必要な試験条件、量子計算による寄与の根拠、モデル上の仮定値との区別 |
| 容量を一定にした電池パックの軽量化 | 電池パックの重量エネルギー密度（Wh/kg）と、電池セルの値を区別する。非電池質量・積載・走行条件が共通か。寿命・安全性や予測精度の改善を電池パックの軽量化へ読み替えていないか |

資料の書誌・パス、版、該当節・表・JSON項目を保存する。所在のみ確認、本文一部確認、該当箇所確認、未取得を区別する。未確認のページ番号や直接引用を作らない。数値がなくても指標と量子計算の役割を保持する。証拠が不足する接続を埋めるために推測を追加しない。

複数の専門家の説明を接続する場合は、対象事例、前提、量の定義、材料・セル・パック等の階層を照合する。一致しない区間は未接続として残す。多数決を因果的真実の判定にしない。

## 6. M0–M1改訂規則

| 条件 | 研究者が検討する扱い | 必須記録 |
|---|---|---|
| 明示的に支持された | 根拠・適用範囲付きで維持する | 明示的な支持の原文、根拠、対象範囲 |
| 条件が限定される | 成立条件を追加・限定する | 適用条件、不成立条件、境界 |
| 用語・変数の意味が不十分 | 定義を精緻化する | 元の意味、変更後の意味、単位・対象の対応 |
| 既存の属性・条件では重要な接続を説明できない | 必要最小限の構造修正を検討する | 属性追加だけで不足する理由、代替構造、根拠 |
| 初期説明に反する具体的根拠がある | 対象範囲を明示し、不支持・削除・別構造を検討する | 反例の対象条件、原文と独立資料、代替説明 |
| 発言や根拠が不足する | 保留する | 専門外、言及なし、資料不足、未解決の不一致 |
| 現在の経路外の知見 | 記録し、自動的に経路を追加しない | 現行範囲との違い、採否を判断していないこと |

「指摘されなかったため、基準版の記述を変更せず残した」と「明示的に支持されたため維持した」を別に記録する。前者に支持の証拠を付与しない。「回答できない」「言及なし」を不存在・不支持へ変換しない。最終成果が不変だったという理由だけで中間リンクを削除せず、途中の変化、相殺、閾値、計量範囲、欠測を確認できる範囲で区別する。

専門家が提案した変更と、研究者が採用した変更を分離する。専門家の確認を採択義務とせず、採否の理由を原文と資料へ追跡できるようにする。新しい因果パスの完成を専門家へ要求しない。

13主変数・13接続・2効果修飾という既存構造基準と、4図の説明上の箱・矢印は別の単位である。描画上の分割を新規採択件数に換算しない。交通条件の表示上の矢印と既存の効果修飾リンクも自動的に対応付けない。電池から定時配達率への直接経路を追加しない。

M0は面接前の登録版として保持する。面接結果の反映先をM1とし、M0へ遡及して書き込まない。面接中の図への書込みは個別の一次記録であり、M0正本の変更ではない。提示資料を途中で変更する場合はプロトコル第11節の版更新規則に従い、各面接の使用版を記録する。

## 8. 結果構成と報告上の限界

結果は、対象の関係について、M0の説明 → 原発言と文脈 → 原文照合の判定 → 独立資料と証拠範囲 → 研究者の改訂判断 → M1での記述 → 残る限界、の対応が追跡できる構成とする。経路①は定時配達率、経路②は同じ配達を期限内に完了する条件での走行時のバッテリー消費電力量、経路③は容量を一定にした電池パックの軽量化による走行時のバッテリー消費電力量に対応付ける。

結果が得られていない現時点では、上記を予定する報告形式として示す。面接件数、支持件数、飽和、M1の変更件数を作らない。専門家の説明との整合、文献の裏付け、既存の限定シミュレーション、実配送での成果を別の証拠状態として示す。

提示による誘導、専門家の選定と経験の偏り、回顧的説明、研究者の解釈、資料取得の偏りを記録する。RIQを用いたことだけで客観性や因果同定が保証されるとはしない。新しい実験、数値モデルの実装・校正、量子優位性の実証、計算資源見積もりを、この面接研究の完了条件へ追加しない。
