## 今回回復できた詳細

ss521の採用値は順に0.65148273、0.93035232、1.18813494、1.45298673回/週である。対象は東京都市圏居住かつ過去1年に宅配受取経験のある世帯に属する回答者10,000人である。原表A41–A44で条件・単位・サンプル加重を確認した。

参照値0.8498914166013274回/週は、この四値を合成世帯の人数構成で加重した値と完全に一致した。原表の総計E39=1.0011625を採用した値ではない。頻度の絶対水準で大田区総量を推定するのではなく、別に決めた82,023 PEを配分するための相対情報である。

採用強度CSVの`source`は`household_type_code=10 subtotal`と記しているが、実表で小計10なのはB列の**世帯構成コード**である。人数コードはA列の1–4である。数値の対応は確認できたが、ラベルは説明上の不正確さとしてここに記録する。既存CSVは変更していない。

住宅統計の総数E4989=397,700に対して四区分の公表値の和は397,710であり、10の差がある。今回のセル確認だけで、生成器がどちらを分母にしたかや丸め差の処理を断定しない。合成住宅型は一戸建92,040・共同住宅285,782・長屋4,753・その他1,778である。これらは住宅数に基づく研究上の割当であり、実世帯の居住建物の個票ではない。
