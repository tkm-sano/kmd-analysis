# D・Wの統計的解析規則

2026-11-17の最新研究判断に基づく。正本は[二目的研究方針](DW_RESEARCH_POLICY.md)と[現行設定](../../configs/toc_delivery/dw_policy_20261117_v1.json)。旧本文は[変更前の保存版](../audits/dw_policy_20261117_v1/before/docs/research/DWT_STATISTICAL_PROTOCOL.md)に保全する。

## 対象量

固定需要の手法別独立外側試行について、採用された検証済み計画のD/W分布と、全開始試行の取得状態を併記する。独立乱数で初期化した手法間は独立群であり、seed番号や反復番号だけで対応付けない。成功集合が異なる場合、差は各手法の成功条件付き平均の差である。失敗を含めた無条件の優劣へ読み替えない。

S1〜S3は同じfamilyの入れ子で各M=1。固定需要内の試行変動と需要間変動を区別する。現在の試行数・shotsでは需要間一般化を得られない。Aの反復は決定的D/Wの確認であり、独立品質標本数は1。複数A出力のD/Wが異なれば不整合として停止する。

## 探索的再分析

各規模・手法の登録／未開始／未完了／失敗／採用を表示する。取得率の分母は全確定開始試行であり、入力失敗や中断も含む。未完了の開始試行があれば全開始の率・区間は保留する。全件成功でも成功確率1を保証しない。WilsonとClopper–Pearsonの点ごとの95%区間を使う。

D/Wの生値・平均・中央値・標本SD・範囲を記述する。D−C、D−B、D−AおよびD−古典置換を規模別に比較する。C/D等は独立Welchの平均差95%CI、固定Aとの比較はA値に条件付けた候補側の平均差区間を用いる。正規近似・有限分散・小標本の限界を記す。標本数不足や両群0分散は理由付きnullであり、0幅CIを作らない。

副次区間は探索的・個別の区間であり同時保証ではない。p>.05、同じ観測距離、0観測分散を同等性・非劣性の証明にしない。取得率の違いを隠して成功品質だけで総合優越を主張しない。

## 仮説全体と本実験

採用文の「いずれと比較しても」はA/B/Cの全比較を要求する。総合評価の正規化・重み・平均等の推定対象・全比較の支持規則が未定なので、現時点で研究仮説の支持／棄却を確定しない。S2のD−C距離差は従来からの主要候補であり、それだけでは二指標総合仮説を検証できない。

本実験の主比較family、必要精度、固定反復数、失敗の扱いと多重性を先に登録する。需要間の推論を行う場合は独立family単位の設計を別途必要とする。T、旧J、時間付きEAF、初到達時間の推論、T用反復数をこのプロトコルに含めない。
