# 専門家インタビュー研究設計総括書

**版：1.0.1／2026-10-21（Asia/Tokyo）**

本書は研究工程、結果構成、適用範囲と限界の総括である。図・前提・質問の正本は[プロトコル](EXPERT_INTERVIEW_PROTOCOL.md)、面接前モデルM0の識別情報は[M0登録情報](EXPERT_INTERVIEW_M0_MANIFEST.json)である。設計文書化済み・面接未実施・面接後の改訂モデルM1未作成であり、実施状態と計画を区別する。

## 1. 研究目的・研究課題・仮説

### 研究目的

必要な配送需要の充足と、そのサービス提供に伴う運用電力量の低減を両立する観点から、量子技術が電気自動車を用いた配送に影響を及ぼす仕組みと、その効果の成立条件を明らかにする。

量子技術が必ず改善効果をもたらすことを前提とせず、効果が成立しない条件や逆転する条件も対象とする。

### 研究課題

量子技術のうち、どのような技術が、どのような仕組みを通じて、電気自動車を用いた配送の需要充足と運用電力量に影響を及ぼし、その効果はどのような条件で成立するか。

### H1：計算方法の相違による運用電力量への作用

量子計算は、古典計算とは異なる計画取得過程を通じて、配送・充電の運用に作用し、配送需要充足と運用電力量に異なる影響を及ぼし得る。

異なる経路の取得を成立の必須条件とせず、計画取得可否・取得時間等の相違も扱う。

### H2：電池性能の媒介効果

量子化学計算の成果が実用電池性能の改善につながる場合、電池性能の変化は車両・充電条件を通じて、配送需要充足と運用電力量に影響する。

材料計算の成果と、材料・セル・パックを経た実用電池性能の改善を区別する。

### H3：周辺条件による効果の変化

H1およびH2の効果の方向と大きさは、交通状況、運転特性、充電条件等の周辺要因との相互作用によって変化する。

上記の目的・問いはREADMEの採用済み表現、H1〜H3の本文はREADMEに記録された正式凍結版v1.0.1の文言を保持する。正式凍結資料の名称は `RESEARCH_OBJECTIVE_RQ_HYPOTHESES_FREEZE_20261014_v1_0_1.md` であり、公開リポジトリには同梱されていない。仮説の支持・棄却は未判定であり、今回のインタビューを仮説の直接的な因果検証とは位置付けない。

正式本文の広い範囲と、今回採用した面接範囲を区別する。面接では、定時配達率と走行時のバッテリー消費電力量について、量子技術の関与と成立条件を検討する。正式目的・研究課題・仮説中の「需要充足」「運用電力量」「周辺要因」等は原文を保持する。正式本文中の充電等への言及を、新しい面接経路の採択根拠にはしない。

|---|---|---|
| 事前資料の照合 | 正式本文、既存実験の条件・結果、方法論の確認範囲を整理する | 本作業の確認範囲をプロトコルとM0登録情報へ記録済み。未取得資料を明示 |
| 面接前基準版の登録 | 4図・前提・質問・境界・改訂規則をM0として識別する | 用語修正版1.0.1を文書化・ハッシュ登録 |

| 専門家インタビュー | 前提共有 → 対象事例 → 図と中心質問 → 必要な追問 → What-if（仮想条件についての質問） → 記載・根拠確認 | 未実施 |

一般的な仮説とモデルの前提を先に示し、その成立・不成立、反例、代替説明を尋ねる。対象をパラメータの網羅的抽出や専門家によるモデル設計へ戻さない。パラメータは回答をモデルへ対応付ける研究者側の記述要素である。

## 4. 一般仮説・技術差・未確認接続

| 区分 | 本研究での扱い |
|---|---|
| 一般仮説 | 計画が現場で選択・共有・実行へ反映される場合の配達結果、同じサービスを保った短時間化と省電力化、固定容量の軽量化を条件付きで提示する |
| 技術差 | 従来と量子の処理・情報・判断、共通する部分、追加的貢献の根拠を具体例に即して確認する |
| 未確認接続 | 計画作成上の改善が実際の配達結果に反映される関係、材料について得られる情報が実用化された電池パックの性能に反映される関係などを仮説・推論として残す |

「量子計算でより多くの条件を同時に考慮できるとしたら」は検討仮説である。条件を増やした効果と、同じ条件を量子方式で解いた追加効果を分離する。旅行時間短縮だけを省電力の根拠にしない。

電池では、基礎技術、量子計算の役割と従来との差、性能指標、確認された数値・比較結果、容量を一定にして電池パックを軽くする前提の適否を簡潔に尋ねる。モデルの主な入力は電池パックの重量エネルギー密度（Wh/kg）である。材料の物性・特性、電池セルの性能、電池パックの性能を区別し、各数値が実測値・計算結果・開発目標のどれであるかも確認する。数値回答を必須とせず、予測情報の改善を実物の改善へ、寿命・安全性を重量エネルギー密度へ読み替えない。電池セルの性能向上が、そのまま電池パックの性能向上につながるとはしない。

補足的に、時間帯別の交通混雑、信号による停止・再発進、通行規制、迂回路・代替経路の有無などの交通条件を尋ねる。交通条件の一般的な影響と、従来方式から量子方式へ変更した場合の差が交通条件によってどう変わるかを区別する。交通情報の利用と実際の交通状態も分離する。電池温度・寿命・劣化は独立した質問群にせず、性能値を解釈するために必要な試験条件として記録する。

## 5. 評価境界と既存定量結果

定時配達率は、固定した評価対象の配達のうち、定められた期限までに配達作業を完了した割合である。既存モデルの「期限内需要充足率」に対応する表示名称であり、分母・完了判定・欠測の扱いは変えない。未配達を分母から除かず、配達先への到着と配達作業の完了、配達の未完了と記録の欠測を分ける。同じ率でも期限内に完了した配達先が一致するとは限らないため、各配送先での配達完了状態・完了時刻を保持する。利用できる配送計画がないことは配達の未完了と区別し、配送計画を取得できた割合を定時配達率としない。

走行時のバッテリー消費電力量は、対象の走行区間で、車両の駆動と車載機器（補機）の消費から、電池に受け入れた回生による回収分（受入回生）を差し引いた正味の電力量である。同じ計量範囲を用い、交通上の一時停止を含め、配達作業の停車、充電、その他の待機を区別する。計算設備・量子計算機・拠点・車外充電損失・製造は加算せず、端子の正味計測と成分別集計を二重加算しない。未配達による低消費は同じサービスの省電力化ではない。

既存の旅行時間は顧客間・デポ間の有向OD道路旅行時間であり、配達作業時間と時間窓待機は最適化目的に加えていない。計算時間とも区別する。計画上の旅行時間と実際の旅行時間、旅行時間と配達作業を含む所要時間を混同しない。配送計画案の取得、実際に使用する配送計画の選択、その実行も別の段階である。表示用語を変えても、保存仕様・式・変数IDを変更しない。

| 保存資料から確認した事実 | 適用範囲と留保 |
|---|---|
| 古典側は固定集合の訪問順を求め、量子側は3・4顧客の理想QAOAを実行 | 量子実機・実運用効果ではない。道路旅行時間評価と電力量評価は別工程 |
| 3顧客78/78、4顧客64/78の経路取得。4顧客では同一59・異経路5 | 未取得14を配送不可能・消費ゼロとしない。共通64は取得条件付きの比較 |
| 電池容量20 kWh、電池パックの重量エネルギー密度180・220・250 Wh/kg、保存軌跡を共通使用 | 仮定した電池性能による質量感度。量子材料研究による実現値ではない |
| 平坦路、回生なし、補機除外、効率0.9、積載0 kg | 限定的な駆動電力量。実配送の積載や最終成果指標全体を評価していない |
| 4顧客の固定4タスク、開始期限＋サービス時間というモデル上の完了期限の設計 | サービス完了再構成の技術検証は未完了。定時配達率の成果は未算出 |

## 6. 原発言・解釈・証拠を分離した分析

[回答票](EXPERT_INTERVIEW_RESPONSE_TEMPLATE.md)は、比較する事例、仕組みの違い、次の判断・運用への接続、What-if、根拠と未確認事項、図の修正・確認、の6区分である。空欄、専門外、説明なし、資料未確認等を許容する。説明の状態と実証状態を区別する。

[分析ガイド](EXPERT_INTERVIEW_ANALYSIS_GUIDE.md)では、処理順序・情報受渡しを技術記述、指標定義・算術を定義・式として検査し、条件付き因果関係へRIQの原文照合を適用する。What-ifは仮想条件に関する説明として保持する。4図全体を厳密な因果ループ図（CLD）と呼ばず、形式のためのループ・極性を追加しない。

判定は、①原文がM0と整合するか、②説明の実際の成立をどの証拠でどこまで確認できたか、の二軸に分ける。原文にない前提、別の解釈、資料間の条件差も残す。文献に基づく事前仮説、実際の発言、研究者の解釈、独立資料は別々に保存する。専門家の記載確認は因果関係の実証確認ではない。

## 8. 適用範囲と限界

面接は、3経路の成立条件と説明の不一致を検討するものであり、量子技術の因果効果量や優位性を同定する実験ではない。提示による誘導、対象者・事例の選択、回顧的説明、研究者の解釈、独立資料の不足を記録する。仮想的推論と経験的反証を区別する。

電池から定時配達率への直接経路は追加しない。充電最適化、貨物再割当、車群増強、量子センシング、交通信号制御を主経路に増やさない。範囲外の知見は記録しても自動採択しない。新しい数値シミュレーション、量子優位性の実証、計算資源見積もりは必須成果ではない。

専門家の支持、M1への採択、文献の支持、モデル内の算術・数値結果、実配送での効果は別の状態である。既存計算の背景交通なし・固定軌跡・回生なし・補機除外・空荷の条件から、実運用の省電力や定時配達率の改善へ一般化しない。
