# 結果未閲覧段階の選択規約訂正

2026-11-15、最初のplan01は`UNKNOWN_STATION_PREVIOUSLY_USED`で停止した。評価ルートの選択確定・学習・推論・採点より前のメタデータ確認である。

最初の一覧は過去eval集合で使用した16拠点だけを調べ、DLA7/DLA8を未使用と説明した。しかし、過去pilotを含む`prior_station_days`にはDLA7の2018-07-31が存在した。DLA8には過去使用を確認しなかった。この事実を利用者へ訂正した。

未知拠点の意味を「今回学習するモデルに含めない拠点」と明示した。DLA7は過去pilotで既知、DLA8は過去解析でも未使用という差を記録する。両拠点を学習候補から除き、全ての過去使用ルートIDと拠点日を今回の抽出から除く。両拠点は固定したままであり、結果の良い拠点へ取り替えていない。

本試験は既存結果を知った上での小規模再現であり、完全盲検の事前登録ではない。`eval_actual.json`を一度スキーマのキー確認に読み込んだが、新規選択ルートの具体的順序・scoreを選択に利用していない。選択確定後は学習側の実績だけをモデルへ渡し、評価実績は全提案固定後に採点へ渡す。
