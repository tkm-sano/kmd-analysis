# 少数batch・資源の受入

少数batchの独立検算 **5,249項目、不一致0**。これを確認してから全件に展開した。入力・出力SHAは `BATCH_ARTIFACT_HASHES.json`、科学コードSHAは `BATCH_GATE.json`、試行元は各 `*_BATCH_SOURCES.json`。原入力は変更なし。

Aは同順・異順・未取得切替・正出発遅延・早着待機を含む4政策、成功例の機構arm12、計80task。期限等号／超過は元実入力に基づく2境界fixtureで、D10全件母集団へ混ぜていない。BはR0…R5と参照欠測を含む7入力560参照（exactあり5／なし2）。Cは4固有速度、T08 48行、T09 5行（FAIL含む）、bridge224行を再計算。

事前合計見積361.321秒、RSS screen2,003,058,688bytesは、wall1,800秒・process4GiBの上限内。row比例のI/O込み概算で、全件実測ではない。モデル改善は受入基準に使わない。Cの既存FAILは計算失敗と別で保持する。

主全件実測はA 2.113秒／182,452,224bytes、B 19.950秒／814,743,552bytes、C 58.939秒／633,241,600bytes。並行実行を含むprocess別wallで、合計を全作業の経過時間としない。CPUはprocess累積、wallはmain内timer、RSSはprocess peak。科学solverの保存CPU時間とは別である。

全件A/B/Cの独立照合756,579項目、統計照合16,090項目、主出力14CSVの再実行hash一致。原道路受入や実車性能のPASSではなく、固定モデル算術のPASSである。
